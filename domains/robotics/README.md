# 机器人领域内核 — DR-059 / DR-060 / DR-062 / IR-016 T03

当前仅提供离线构建、RDF 语义读取、固定模板实例化和符号检查。
公开调用入口接受显式输入，不依赖 yang 归档路径，不读取导入时资产，也不启动服务或连接机器人。

| 模块 | 职责 |
|---|---|
| importer、source_validation | 校验受支持的 XML/profile 与模型一致性，保存来源摘要并确定性构建 RDF |
| graph | 原领域词表与 RDF 构建原语，保留类、实例与类型化属性 |
| profiles/ur_pick_place | 四棵树的固定步骤、角色、复合接口、条件及未确认示例知识 |
| semantics | 只读 RDF 恢复执行树、节点契约及公开参数位置，不解析归档 sourceNodeXML |
| compiler | 基于明确基线和图中推导的位置绑定公开配置，输入模板不被修改 |
| validator、xml_contract | 模板一致性、数值/接口校验及符号数据流，不推断真实执行成功 |

算法来自已在 T01 记录摘要的 yang 构建侧函数，按职责提取，未整包保留旧服务或通过 sys.path 转发调用。
源文件中未写类型的 SubTree 接口从内部原子端口唯一推导；原子端口模型的方向和类型冲突必须拒绝。
固定步骤定位只保留在受明确模板约束的 UR 来源知识抽取中，编译公开参数位置从 RDF 绑定推导。

compiler.instantiate 是结构性原语，不能直接作为面向用户的正式生成 API。
allow_unresolved 默认为 false；显式作者草稿选项保留给后续策略适配，不能据此绕过未来任务证据闸门。
发布封装、消费契约、业务实体/适配证据准入、平台 API 与演示命令尚未完成。
