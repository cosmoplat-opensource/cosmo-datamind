# IR-014 · 本体构建、后端安全、交互恢复与 SDD/TDD 验收

## 目标 Goal

针对可复现的算法、系统和交互缺陷完成“规格 → 失败用例 → 最小修复 → 综合验收”的闭环。
保持单机工作台定位与现有 UI 设计，不将数据连接可用性宣称为业务语义正确性。

## 交付 Deliverables

- [x] 完整 SQLite 关系证据、联合复合 FK、声明约束完整性检查与有界构建。
- [x] 指标状态新鲜度、人工决定保护、参照重放、精确比较与并发变更检测。
- [x] CSRF/Host/SSRF/SQL/请求行时限及 API 物化事务修复。
- [x] 构建 SSE 恢复、异步选择防串线、结果转义与响应式交互。
- [x] 默认隔离 pytest、统一检查入口、需求到行为测试的可检验映射。
- [x] 全量 HTTP、十轮变序、浏览器和依赖审计完成并记录实际结果。

## 任务 Tasks

1. 读取系统架构、构建技能正文、历史决定和现有实现，建立测试基线。
2. 分别为算法、安全、指标与 UI 添加失败复现，保留 RED/GREEN 证据。
3. 修复共享原语并对齐 LLM/离线分支，独立交叉评审边界。
4. 在临时工作区执行完整检查，修复综合回归暴露的问题。
5. 写入审计报告和未覆盖边界；代码留在工作区供审阅，不自动提交或发布。
