# IR-013 · 标准资产本地化与目录加载恢复

- **状态 / Status**: delivered
- **日期 / Date**: 2026-09-01
- **关联 / Refs**: [[DR-052-build-industry-and-standard-references]]

## 目标 Goal

消除构建页永久停在“目录加载中”的失败形态，并让标准选择实际读取固定版本、合法
再分发的本地机器可读资产，而不是只依赖代码内硬编码名称。

## 交付 Deliverables

- [x] 前端模块到达时同步装入完整离线目录；服务端目录随后核验和增强。
- [x] 接口 404、返回异常或 8 秒超时时保留全部选项，显示原因和“重新加载目录”。
- [x] HTML/自研 JS 使用 no-cache，目录 API 使用 no-store，脚本 URL 带版本参数。
- [x] 固定版本纳入 BFO 2020、IOF Core/Annotation Vocabulary、gUFO 1.0.0。
- [x] 纳入 MESA B2MML V0701 的 33 个 ISA-95 XSD；保留许可和署名，不复制付费正文。
- [x] `standard_assets.py` 离线解析 RDF/XSD，报告文件数、规模、来源版本、许可和指纹。
- [x] 标准资产事实进入提示词、质量报告、构建 manifest 与逐轮历史。

## 验收 Acceptance

- [x] 新旧服务不匹配或目录请求失败时，四种行业和四种标准选项仍立即可见，不残留“加载中”。
- [x] 三组标准资产均可本地解析且内容指纹固定；运行时不跟随 import 发起网络请求。
- [x] 标准资产缺失时不伪装为已加载：软参照进入复核，强约束阻断验收。
- [x] API、静态模块、提示注入、manifest、许可边界和浏览器交互均有回归覆盖。
- [x] 全量 pytest 389 项通过；覆盖率 89.6%，`standard_assets.py` 88.8%；隔离 WSGI
  系统回归 548 项通过、0 失败、8 项因上游本体引擎未提供而条件跳过。
