### 最小存储约定

工作目录通过调用方显式传入，演示与测试使用独立目录，不默认操作用户当前业务文件。
同一存储根下使用一个 SQLite 数据库协调资产、版本、运行、事件和工件索引，文件置于其受控子目录。
版本固定 `ontology_id / version_id / parent_version_id / domain / payload_kind / payload_sha256`，并保留来源、配方、profile、协议与验证引用。
数据载荷为有效 IR 的 JSON 快照，机器人载荷为完整发布 OWL 字节；展示投影不成为第二份权威载荷。
身份以资产、版本与实体引用共同限定；不同资产包含相同 IRI 时仍是独立记录。
同一资产的新增版本不得改写旧载荷，父版本必须存在且属于该资产；已发布版本引用不会随最新版本指针移动。
机器人版本标记可发布前必须经过现有消费契约复验；仅有文件入库不能取得该状态。
运行生命周期与业务结果分开：例如执行正常结束但业务返回 `needs_information`，不应记为产生候选。
运行固定输入、资产版本、模式和执行组件版本，禁止凭“当前最新版”回填旧记录。
运行及事件更新在事务内完成，事件在各自运行内单调递增；并发写入不得丢失、重复序号或跨运行串写。
启动恢复由单一宿主显式执行一次，不因每次打开数据库就中断活跃运行；遗留 running 标记 interrupted，重试创建新 run 并关联原 run。
工件先写入并核验摘要，再事务登记索引与终态；中途失败可留下未登记文件，但不得留下可见的成功记录或半份清单。
工件读取只接受登记标识，核对所属运行、受控路径与摘要；缺失或损坏明确报告，保留原始历史，不静默返回旧文件。
manifest 记录运行、会话引用、固定本体版本、来源、profile/编译器/规则、任务和参数依据、工件 ID/媒体类型/摘要。
清单不包含密钥，也不将自己纳入自身摘要；本轮未调用模型时明确记录未调用，不伪造模型配置或提示词版本。

## 验收 Acceptance（范围已确认，交付尚未完成）

- [ ] **AST-01 双领域目录**：同一目录能列出有效数据 IR 快照和机器人 OWL，载荷类型及可用应用明确；机器人资产不被当作 SQL 数据源或触发默认演示库兜底。
- [ ] **AST-02 不可变与保真**：来源字节和摘要可复核，机器人 OWL 字节及 RDF 语义保留；新版本不覆盖旧版，指定旧版本生成不受新版影响，错误父版本、非法载荷和协议不被发布。
- [ ] **AST-03 身份与旧图谱适配**：相同 IRI 不跨资产或版本误合并；数据快照包含已有有效编辑，重复登记行为确定；来源更新只影响显式新登记，不改历史快照。
- [ ] **AST-04 运行与会话关联**：新进程可读取固定输入、版本、状态、结果与事件，同一会话可关联多个运行；业务拒绝有报告但无候选，现有聊天正文不被复制、覆盖或重写。
- [ ] **AST-05 恢复与事件一致性**：显式启动恢复只中断遗留 running，不改已终止结果，重复恢复幂等；重试新建 run；并发事件无丢失或重复序号，非法状态转移及终态覆盖被拒绝。
- [ ] **AST-06 工件提交与清单**：成功记录指向实际存在且摘要匹配的工件；注入文件写入、摘要核对、数据库提交故障时，不出现伪成功或部分可见索引；清单追溯固定版本、任务及参数依据，不含凭据。
- [ ] **AST-07 路径与完整性**：任意路径、跨运行工件引用和符号链接逃逸被拒绝；文件缺失或篡改可诊断且不返回可信成功；未知数据库 schema 不静默重建或丢弃已有数据。
- [ ] **AST-08 旧能力保持**：旧图谱、编辑、问数、聊天与 jobs 行为无新增回归；测试在隔离工作目录运行，不改用户业务目录；不降低既有 lint、类型或覆盖率门槛。
- [ ] **AST-09 可直接复核**：以下离线命令实际可执行；独立进程重新读取目录与历史，核对版本、事件、清单和工件；运行中断可恢复为 interrupted，真实缺证据仍阻断候选；重复演示不覆盖前次结果，全量检查通过且跳过原因有记录。
