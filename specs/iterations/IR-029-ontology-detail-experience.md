# IR-029 · 本体详情与应用修复体验

- **状态 / Status**：proposed（规约草案，未进入实现）。
- **日期 / Date**：2026-11-12。
- **关联 / Refs**：[DR-075](../decisions/DR-075-ontology-detail-experience.md)。

## 目标 Goal

新机器人详情虽然已经展示 TBox、ABox 和覆盖信息，但长表格、原始字段和缺少任务导向的层级使内容难以理解。
布局可先实施；应用和删除动作分别依赖 IR-025／IR-028，完整端到端验收在 IR-026／027 之后。

## 交付 Deliverables

- [ ] 冻结接口、状态语义和兼容规则。
- [ ] 对应服务、存储／适配实现及前端接点。
- [ ] 失败诊断、来源与版本追溯。
- [ ] 红绿测试、迁移验证、全量回归和使用文档。

## 任务 Tasks

- [ ] T01：冻结详情信息层级、计数口径、应用状态文案、修复返回流程及桌面／窄屏布局；确认 ODE-01～04。

- [ ] T02：RED：覆盖摘要计数、类别／实例区分、空业务分组、分页搜索和过期状态展示；提交人审。

- [ ] T03：GREEN：复用现有样式完成详情框架、摘要卡、标签页及搜索分页，避免首屏渲染全部 JSON。

- [ ] T04：RED：覆盖浏览不检查、行为树按钮在未检查／有缺项时可进入诊断、修复深链与返回、固定版本下载、任务上下文、删除恢复和新旧入口；提交人审。

- [ ] T05：GREEN：连接应用检查及修复动作，完成加载／错误状态与键盘操作；真实浏览器核对桌面和窄屏。

- [ ] T06：使用真实新本体副本、旧 UR 和数据本体完成视觉与流程回归；记录前后对照、性能基线并人审交付。

## 验收 Acceptance

- [ ] ODE-01：桌面与窄屏无横向溢出；360 实例分页／搜索流畅，初始页面不倾倒全部原始 JSON。
- [ ] ODE-02：类别数与实例数分开，空业务分组不误报空本体，四种检查状态不混淆。
- [ ] ODE-03：浏览不触发检查，行为树按钮在未检查或有缺项时仍可进入诊断补全；修复深链带版本，过期结果不授权实际生成。
- [ ] ODE-04：新旧详情和数据本体入口无回归，完整 JSON／OWL 下载仍绑定固定版本。
- [ ] 现有全量检查通过；没有修改已审测试来放宽要求。

## 回退与交付

新增能力使用服务端开关和版本化配置；回退不改写既有资产。
检查与运行记录保持可追溯，删除保护和执行守卫不可因关闭展示功能而绕过。
测试路径在 T02/T04 创建后进入正式 requirements；当前只登记 planned_requirements，不宣称通过。
