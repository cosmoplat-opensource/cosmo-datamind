# IR-022 · 机器人本体关系图与行为树视图

- 状态：in-progress。
- 日期：2026-11-09。
- 关联：DR-063、[DR-068](../decisions/DR-068-robotics-readonly-graph-views.md)。
- 范围依据：用户后续明确要求暂不展示构建来源行为树；本体关系图与任务结果行为树保留。

## 目标

在平台内浏览固定机器人本体版本的关系；行为树仅通过具体任务生成结果向用户展示。

## 交付

- [ ] RDF 关系/行为树只读投影与 HTTP 接口。
- [ ] 入口、关系画布、节点详情、筛选搜索和视口控制；来源行为树页面暂停展示。
- [ ] 自动化测试、浏览器验证与使用说明。

## 任务

| 任务 | 内容 |
|---|---|
| T01 | DR/IR/acceptance 与失败测试 |
| T02 | 投影、只读接口、G6 页面及入口 |
| T03 | 回归、浏览器验收与交付记录 |
| T04 | 修复实际画布缩放、补充子树返回、简化本体卡片入口及回归 |
| T05 | 统一图谱与任务页的历史感知/放置配置名称，并验证不改写 OWL |
| T06 | 暂停来源行为树展示，替换过时的来源树 UI 验收，回归任务结果展示 |

## 验收

- [ ] 本体库选择机器人本体“打开图谱”，显示对应版本的命名实例及真实关系；业务/技能/全部筛选、名称搜索、节点详情、拖动缩放与重置可用。
- [ ] 本体详情和关系图均不提供来源行为树入口；旧链接及刷新只显示任务生成引导，不请求或渲染来源树；任务生成后的预览与下载可用。
- [ ] 关系图显示本体名称与可读版本号；刷新保留固定版本，切换不残留旧画布/异步数据。
- [ ] 缺失版本、非机器人本体、篡改数据、超限投影显示明确错误，无静默截断。
- [ ] GET 不写库、不调用 LLM，不改变既有数据本体图谱与任务结果展示。
- [ ] 文字/参数按文本展示，窄屏可用，图形操作提供列表选择和节点详情的键盘替代。

- [ ] 机器人卡片只显示“打开图谱”一个操作；经图谱进入详情后可生成行为树。
- [ ] 关系图选中节点前后的加减按钮、滚轮均改变实际画布，适应画布有效。

- [ ] 图谱节点、名称搜索、节点列表、详情及关系列表与任务页使用相同配置名称，不再把旧名称中的“尚未绑定”作为状态展示；不改写固定 OWL 或用户自定义名称。
