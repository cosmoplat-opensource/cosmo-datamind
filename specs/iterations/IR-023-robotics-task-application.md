# IR-023 · 行为树生成应用与历史记录

> 引用的开发中间材料仅保留本地副本；历史记录不代表当前版本已验证。

- 日期：2026-11-09。
- 关联：[DR-151](../decisions/DR-151-robotics-task-application.md)。
- 范围依据：用户要求同级导航、图谱直达、一对多生成和带本体名称的历史记录，风格与问数一致。

## 目标

从“本体应用”直接创建机器人任务或查看历史结果，无需绕经本体库详情。

## 交付

- [x] 只读历史列表、固定运行结果及下载接口，复用现有存储。
- [x] 独立应用首页、历史侧栏、任务工作区与图谱直达入口。
- [x] 自动化测试、浏览器验证、使用说明及审计记录。

## 任务

|任务|内容|
|---|---|
|T01|DR/IR、验收映射及失败测试|
|T02|历史接口、任务描述与时间、应用工作区及导航|
|T03|回归、真实浏览器验证与交付记录|

历史使用说明现仅保留本地；公开应用范围见[行为树生成应用决策](../decisions/DR-151-robotics-task-application.md)。
六项专项测试见[验收映射 RTA-01](../acceptance.json)。

## 验收

- [x] 本体应用下可直接打开行为树生成，原深度问数入口及功能保留。
- [x] 图谱按钮固定所选版本；首页可选择本体；同一本体的新任务互不覆盖。
- [x] 历史显示本体名称、版本、任务描述、状态和时间，可搜索和分页，旧任务/旧结果可发现。
- [x] 同一会话多次生成分别可查看，旧结果固定运行、XML 预览与下载一致；刷新和服务重启后仍在。
- [x] 浏览首页、历史、旧结果不调用模型、不创建会话、不改写本体；无数据及功能关闭时有明确状态。
- [x] 非本会话运行、构建运行及损坏工件不能冒充历史行为树。
- [x] 界面与问数风格一致，窄屏无横向溢出，错误与加载状态可见。

## 原交付时的验证记录

该阶段的 4 项后端和 2 项浏览器专项检查通过，覆盖任务应用首页和历史结果。
全量检查 12 段通过：后端 1680 项通过、5 项按既有规则跳过，覆盖率 84.4%；机器人构建/图谱、维护和任务浏览器分别 18、16、12 项通过。
维护者于 2026-11-18 确认整轮交付。上面的清单汇总最终交付范围，原计划的逐项人工评审没有单独记录。

## 复核方法

在[项目测试环境](../../README.md#测试)中运行 RTA-01 的后端与浏览器用例。后端用例检查搜索分页、同一会话的多次生成、固定结果下载及错误工件拒绝。浏览器用例检查图谱传入的版本、独立任务的历史结果、服务重启后的只读回查和 390px 窄屏布局。

```sh
python -m pytest -q tests/unit/test_robotics_task_history.py
python -m pytest -q tests/frontend/robotics-task-browser.py -k 'task_application_history_retains_two_generations_and_reopens_without_model or graph_starts_task_with_selected_ontology_version'
```
