# IR-023 · 行为树生成应用与历史记录

- 状态：in-progress。
- 日期：2026-11-09。
- 关联：[DR-069](../decisions/DR-069-robotics-task-application.md)。
- 范围依据：用户要求同级导航、图谱直达、一对多生成和带本体名称的历史记录，风格与问数一致。

## 目标

从“本体应用”直接创建机器人任务或查看历史结果，无需绕经本体库详情。

## 交付

- [ ] 只读历史列表、固定运行结果及下载接口，复用现有存储。
- [ ] 独立应用首页、历史侧栏、任务工作区与图谱直达入口。
- [ ] 自动化测试、浏览器验证、使用说明及审计记录。

## 任务

|任务|内容|
|---|---|
|T01|DR/IR、验收映射及失败测试|
|T02|历史接口、任务描述与时间、应用工作区及导航|
|T03|回归、真实浏览器验证与交付记录|

## 验收

- [ ] 本体应用下可直接打开行为树生成，原深度问数入口及功能保留。
- [ ] 图谱按钮固定所选版本；首页可选择本体；同一本体的新任务互不覆盖。
- [ ] 历史显示本体名称、版本、任务描述、状态和时间，可搜索和分页，旧任务/旧结果可发现。
- [ ] 同一会话多次生成分别可查看，旧结果固定运行、XML 预览与下载一致；刷新和服务重启后仍在。
- [ ] 浏览首页、历史、旧结果不调用模型、不创建会话、不改写本体；无数据及功能关闭时有明确状态。
- [ ] 非本会话运行、构建运行及损坏工件不能冒充历史行为树。
- [ ] 界面与问数风格一致，窄屏无横向溢出，错误与加载状态可见。

## 验证记录

待验证，保留人审交付状态。
