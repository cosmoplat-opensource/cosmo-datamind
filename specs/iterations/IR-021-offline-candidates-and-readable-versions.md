# IR-021 · 简化适配步骤与版本展示

- 状态：in-progress。
- 日期：2026-11-06。
- 关联：[DR-067](../decisions/DR-067-offline-candidates-and-readable-versions.md)。
- 范围依据：用户批准离线生成与适配记录分离，并要求直观版本编号。

## 目标 Goal

信息完整即可生成离线候选，不再强制填写抓取/放置适配依据和有效期。
用户能直接辨认当前版本及保存前后的版本变化。

## 交付 Deliverables

- [ ] 基础任务离线生成策略及状态/报告；严格生成默认契约保留。
- [ ] 折叠可选备注、历史任务接续、短版本编号及版本更新提示。
- [ ] 后端、控制器、浏览器覆盖及旧断言替代清单。
- [ ] 使用说明、回归与人工验证记录。

## 任务 Tasks

| 编号 | 工作 | 完成条件 |
|---|---|---|
| T01 | 规约与 RED | 明确旧适配必填、长 ID 展示断言的替代；覆盖新离线准入和稳定编号 |
| T02 | 后端与 UI 实现 | 只取消适配证据生成门槛，必要参数/结构检查保留；备注不伪造适配结论 |
| T03 | 回归、浏览器验证与交付 | 实查不填依据即可生成，旧任务可接续，版本编号与提示一致；记录实际执行结果 |

## 验收 Acceptance

- [ ] 已确认的对象/映射/参数完整时，无适配证据也能生成并下载 XML，显示“任务适配未验证”。
- [ ] 缺参数、无效参数、歧义目标或损坏结构仍阻止生成；严格生成仍要求适配证据。
- [ ] 缺失/过期/撤销/范围变化均不误报适配有效；执行状态始终未验证。
- [ ] 可选记录无需有效期，保存和刷新后可查看，不改变 OWL、配置版本或适配结论。
- [ ] 历史任务可以接续生成，不因刷新页面自动修改版本或调用模型。
- [ ] 页面显示“版本 N”，新增/分支版本、重启后旧编号不变；保存提示版本变化。
- [ ] 下载、请求及会话仍使用完整内部 ID，不以显示编号作跨本体身份。

## 旧测试替代

HTTP 附件证据测试继续检验证据上传本身不确认适配、明确保存后真实绑定；适配项从必填 gaps 移到 optional_gaps。
浏览器原依据/日期必填测试改为“无依据可生成，备注可保存但不提升适配状态”，正式证据校验仍由领域与 HTTP 测试覆盖。
浏览器版本展示断言改为版本编号，DOM 身份、链接、接口仍验证完整 ID。
其他已审断言不因新需求删除或放宽。
