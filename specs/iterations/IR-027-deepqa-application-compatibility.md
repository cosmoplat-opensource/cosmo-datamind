# IR-027 · 深度问数应用契约兼容

- **状态 / Status**：proposed（规约草案，未进入实现）。
- **日期 / Date**：2026-11-12。
- **关联 / Refs**：[DR-073](../decisions/DR-073-deepqa-application-compatibility.md)。

## 目标 Goal

现有 _qa_graph_profile、_qa_scope_error、_qa_validate_sql 和 metric_contract 已提供数据可查询性与执行前控制；还没有统一应用注册及修复报告。
依赖 IR-025；以影子检查比较现有结果，再启用新增入口诊断；保留最终 SQL 守卫。

## 交付 Deliverables

- [ ] 冻结接口、状态语义和兼容规则。
- [ ] 对应服务、存储／适配实现及前端接点。
- [ ] 失败诊断、来源与版本追溯。
- [ ] 红绿测试、迁移验证、全量回归和使用文档。

## 任务 Tasks

- [ ] T01：冻结旧问数兼容矩阵、可查询子集、指标消费分级、同步／SSE 协议与缓存摘要；确认 DQC-01～04。

- [ ] T02：RED：覆盖有效 IR 编辑层、多图、部分表可用、无模型回退、普通查询和指标问题；提交人审。

- [ ] T03：GREEN：封装 data.deep_qa 适配器，复用可查询性、SQL 和指标检查，提供连接／绑定修复定位。

- [ ] T04：RED：覆盖同步／SSE 结论一致、连接变更、缓存命中前复核、删除 key 和直接请求；提交人审。

- [ ] T05：GREEN：接通问数入口及缓存失效，先做影子比较，再接统一缺项提示；保留最终 SQL 守卫。

- [ ] T06：运行问数基线及真实浏览器回归，核对旧响应兼容和降级路径；记录比对结果后人审交付。

## 验收 Acceptance

- [ ] DQC-01：数据本体构建入库不增加契约步骤；现有问数入口自动绑定契约，单表计数、指标、多图及无模型回退保持原边界。
- [ ] DQC-02：未绑定表／连接不可用提供修复建议；部分可用仍可问可用子集。
- [ ] DQC-03：同步与 SSE 使用相同阻塞结论；旧指标不被新增的全局认证门槛阻断。
- [ ] DQC-04：删除或编辑本体后缓存不能返回旧授权结果，跨领域资产不能进入 SQL 执行。
- [ ] 现有全量检查通过；没有修改已审测试来放宽要求。

## 回退与交付

新增能力使用服务端开关和版本化配置；回退不改写既有资产。
检查与运行记录保持可追溯，删除保护和执行守卫不可因关闭展示功能而绕过。
测试路径在 T02/T04 创建后进入正式 requirements；当前只登记 planned_requirements，不宣称通过。
