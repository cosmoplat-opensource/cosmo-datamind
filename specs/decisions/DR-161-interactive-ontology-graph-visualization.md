# DR-161 · 机器人交互式本体图谱与构建可视化

- **状态 / Status**：accepted（2026-11-17 用户要求按 SDD 启动 IR-031；T01 冻结技术契约作为 RED 依据）。
- **日期 / Date**：2026-11-17。
- **关联 / Refs**：[IR-031](../iterations/IR-031-robotics-interactive-ontology-graph-visualization.md)、[DR-150](DR-150-robotics-readonly-graph-views.md)、[DR-152](DR-152-robotics-dual-build.md)、[DR-155](DR-155-ontology-detail-experience.md)、[DR-158](DR-158-master-development-integration.md)。
- **范围修订**：2026-11-19，按维护者要求，现阶段仅实现机器人本体的交互式图谱；数据本体维持现有可视化和交互，不安排第二轮接入。当前实现交付状态：delivered（相关回归通过）。

## 上下文 / Context

用户希望在机器人本体构建过程中，通过类别圆圈、关系连线、属性展示和实例展开理解本体如何逐步完善。
当前机器人设计已经具有类别、关系与属性、实例构建阶段及持久化修订，但主要以文字和表格展示。
当前机器人关系画布以实例为主，无法完整表达类别设计阶段。
用户要求保留附件交互式本体图谱的主要风格、拖拽时节点联动及双击类别展开实例的交互。
当前仅完成机器人本体构建与已保存机器人本体浏览，不将数据本体纳入这套画布。
数据本体主图、构建结果预览、问数高亮、关系证据、详情和评审继续使用现有实现。
只替换画布会丢失当前本体身份、业务状态和操作上下文，使用户无法判断所见内容来自哪个阶段、版本或数据源。

### 当前基线与来源

附件源码位于 `${INTERACTIVE_ONTOLOGY_GRAPH_SOURCE_ROOT}`。
可复用核心为 `static/graph.js`、`static/model.js`、`static/edgeRouting.js`、`static/labelLayout.js` 及相关视觉样式。
交互式本体图谱的 SVG 渲染、力导向布局与实例展开已有实现，但不理解 Datamind 的修订确认、资产状态或数据证据状态。
机器人接点包括 `ui/modules/robotics-design.js`、`robotics-views.js` 和 `ui/index.html` 中对应的资源加载。
数据本体的 `graph-render.js`、`qa-anchor.js`、`build-stream.js` 不接入该画布，数据构建作业、恢复与取消流程维持原样。

### 方案取舍

| 方案 | 收益 | 代价与取舍 |
|---|---|---|
| 在机器人设计和固定版本浏览中复用图谱组件 | 保留主要交互，同时接回机器人阶段、版本和业务功能 | 本文采用方向；不扩展数据本体入口 |
| 嵌入完整独立交互式本体图谱页面和服务 | 初期能较快看到原页面 | 双状态与文件流程难以接入当前构建和评审，不采用 |
| 在 G6 上重新实现交互式本体图谱的所有交互 | 延续现有图库 | 需重做已存在的交互和视觉，不作为本轮主方案 |

## 决定 / Decision

1. **现阶段仅交付机器人本体。**
IR-031 完成机器人交互式图谱组件、机器人设计阶段可视化与固定版本浏览。
取消数据本体接入的后续迭代安排，数据本体维持原有主图、结果预览和业务交互。
以后如需扩展到数据本体，必须另行确认范围与验收标准，不视为本决定的默认后续交付。
当前范围不包含数据库业务记录实例化、OWL 推理或实机执行。
机器人逐 token 生成节点、交互式本体图谱全量编辑器和新导入格式也不在本轮范围内。

2. **仅在机器人页面之间复用画布。**
机器人设计和固定版本页面使用同一组件，接收只读视图投影、显示状态和交互回调，负责节点、连线、布局、选择、搜索、缩放与展开呈现。
机器人设计和机器人固定版本分别转换权威数据，并提供对应详情及允许的操作。
机器人视图入口保留领域检查，数据本体不能作为该交互式图谱的输入。
视图投影不是新的本体存储，也不替代 RDF、设计会话、评审日志和资产版本。
组件源码纳入仓库，运行不依赖附件绝对路径、独立交互式本体图谱服务或外部 CDN。
复制范围及来源摘要在实施时登记，排除输出截图、备份、发布包和无关编辑器代码。

3. **以真实设计修订驱动连续展示。**
类别阶段显示类别圆圈及已存在的继承关系。
关系与属性阶段在已确认类别基础上显示对象关系，并通过属性标记、详情和按需展开显示数据属性及类型。
实例构建成功后，按对应产物显示类别实例数量、显式类型归属、实例关系和数据值。
每轮结构化结果通过现有校验并保存后更新画布；等待期间保留最近有效结果并显示真实运行状态。
不得根据日志、计时器或模型未完成文本伪造类别、关系或完成状态。
离线构建直接显示真实完成结果，不虚构 LLM 分阶段设计过程。

4. **保持身份、修订与阅读位置。**
投影携带机器人来源身份：设计会话及 revision，或固定 ontology_id/version_id/payload 摘要。
机器人节点以完整 IRI 为身份，视图辅助节点和边使用可重复生成的稳定标识。
显示名称不能充当跨本体唯一身份，机器人节点和关系继续使用稳定的原始标识。
同一来源的有效更新保留仍存在节点的位置、固定状态、缩放、选择和展开状态，并区分新增、修改、删除。
物理布局允许自然移动；不得因轮询或输入框变化反复重新初始化全图。
历史修订明确标识且只读，不覆盖当前设计；切换来源不得带入另一版本的内容或迟到响应。
设计退回类别阶段后，失效的关系、属性和实例不得作为当前有效内容继续显示。

5. **保留交互式本体图谱的主要视觉与交互。**
类别使用蓝色圆圈，实例使用可区分的形状，关系带名称，提供图例、详情侧栏、平移缩放、适应画布和搜索。
力导向模式下拖动未固定节点会带动相连的未固定节点，提供固定／释放和暂停布局操作。
双击类别展开或收起其显式归属实例，多类别实例去重但保留各自归属连线。
当前阶段尚无实例时明确说明原因，不能把类别本身当成实例。
父类的推导实例不自动混入显式实例数量；如将来增加继承展开，需另行明确口径。
Datamind 导航、建模输入与确认按钮承载现有流程，图谱详情承载完整定义、来源和待明确项。

6. **正确表达本体语义与业务状态。**
类别关系、继承、实例归属、实例事实及数据值连线有可辨识的类型和说明。
保留已支持的 unionOf 等表达式语义，不能把多个定义域当作任意等价含义，也不能将类别关系当作实例事实。
设计建议、已确认骨架、候选产物、发布／生命周期和应用可用性继续分别表示。
画布出现内容不产生确认、发布、模型调用、任务执行或隐式写入。

7. **数据本体维持原样。**
数据本体主图、构建完成预览、问数锚定、证据状态、详情与评审保留现有组件和服务，不接入机器人交互式图谱。
不修改数据本体节点／关系身份、角色引用、发布资格、数据源范围或作业语义。
本决定不包含数据本体的新增展示或接口能力，也不改变其既有测试和验证目的。

8. **机器人构建结果与跨页面一致。**
机器人构建仍按现有作业及终态判定完成，不以日志、计时或断流判断成功。
完成实例构建后读取实际输出的固定版本，设计页与版本浏览页使用相同本体身份和载荷摘要。
候选、发布资格和生命周期状态仍由原服务判定，图谱浏览不产生发布或执行权限。

9. **按规模展示并保证生命周期隔离。**
默认先展示机器人本体类别，实例按类别展开；大规模时允许分批、筛选和局部视图，但必须显示已显示数／总数及继续查看入口。
“所有实例”表示对应固定范围内的显式实例均可访问，不要求所有节点同屏，不允许静默截断或近似数量冒充总数。
每个画布实例隔离 SVG 标识、事件、动画与尺寸观察器，多个机器人画布并存时不相互影响。
销毁或离开页面释放资源；快速切换、请求失败和资产删除时按当前上下文处理，不展示旧图作为成功结果。
加载失败提供明确错误与重试，不静默回退到 demo 或第一张本体。
继承 DR-157／DR-158 的生命周期、固定版本读取和当前数据库范围规则。

10. **规约与验证先行。**
机器人范围由 IR-031 维护，视图契约与行为测试随实际改动同步；未实现的测试不得登记为已覆盖需求。
性能验收在 T01 用代表性本体和固定浏览器环境确定节点／边规模、加载及拖拽响应指标，并在实现前记录具体阈值。
浏览器验收必须实际检查拖拽联动、双击、修订更新、切换及布局，不以源码包含关键字代替行为测试。

## 后果 / Consequences

用户能在同一画布理解机器人本体的逐步形成，并用一致交互浏览已保存的机器人本体。
组件与机器人数据投影保持分离，但当前不承诺其它领域的接入或交付。
需要承担 SVG 布局性能、视图状态保持、稳定身份、角色关系和业务操作回接的维护成本。
新增／改动影响主要落在机器人交互式图谱组件、机器人设计与版本页面、投影接口和相关测试；数据图及其结果预览维持现有实现。
机器人固定版本已有详情投影可作为数据基础，但须核对表达式和完整 IRI 信息是否足够，缺失时补只读投影而不猜测语义。
本决定实施后局部替代 DR-150 第 2 条的“仅实例”展示范围与第 4 条的 G6 选型；其固定版本、只读和不展示来源行为树的约束继续适用。
任务生成结果的行为树画布不属于共享本体图替换范围，仍按现有任务应用流程验收。
