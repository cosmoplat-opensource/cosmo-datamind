# DR-078 · 界面与文档用语规范、问数关系图与输入栏排版

- **状态 / Status**: accepted
- **日期 / Date**: 2026-10-04
- **关联 / Refs**: [[DR-069-build-agent-real-model-gaps]]、[[DR-054-metric-contract-and-lifecycle]]、[[DR-077-in-db-dictionary-and-comment-veto]];
  实证=`tests/unit/test_qa_anchor_ui.py`、`tests/unit/test_ui_nav.py`、`tests/unit/test_metrics_ui.py`

## 上下文 / Context

「口径」一词在界面、执行记录、错误提示、模型提示词与文档中被用来指代三种不同的东西:
SQL 执行前对照本体的校验(DR-069 `ontology_gate`)、指标的计算规则(DR-054 指标契约)、以及泛指的「规则 / 一致」。
同一个词承担多种含义,读者难以判断具体所指。

部署环境走查中,问数结果里的关系图(技术证据)在窄面板中被等比缩小到约 31%,字号只有 4 px 左右;
直线从中心连到中心,会从不相连的对象框底下穿过;对象框半透明时,连线压在框内文字上。
问数输入栏在窄面板中把技能、数据源标签挤成 3~4 行的竖条。

## 决定 / Decision

1. **用语按含义区分**(界面、执行记录、错误提示、提示词、MCP 工具说明、技能与现行文档):
   - SQL 执行前对照本体的校验:「本体约束校验」「本体约束拦截」;拦截原因「关联未经数据验证」;
   - 指标:「计算规则」「计算规则卡」「指标定义表」(看板 Excel),业务确认按钮为「业务确认」;
   - 泛指规则一致处改为「规则相同」「统计方式」等;「编码口径冲突」改为「编码字典冲突」,
     碳核算「范围口径」改为「排放范围划分」,重复边「口径二义」改为「语义二义」。
   - 例外:上传 Excel 的表头匹配仍接受「口径」作为「计算逻辑」列的别名(这是用户文件里的写法);
     `docs/audits/` 下的归档证据与 `specs/decisions/`、`specs/iterations/` 的历史记录不改。
2. **问数关系图**(`ui/modules/qa-anchor.js`):
   - 三列、按原尺寸显示,面板窄时横向滚动,不再整体缩小;对象名 13 px、表名 11 px,表名按框宽截断;
   - 直线不穿过其他对象框时画直线,且从框边起止;否则沿网格间的空白通道走折线(行间横向、列间纵向),
     不经过任何无关的框;
   - 图下说明改为「未画出的对象和关系仍在规划上下文中,模型可以使用」。
3. **问数输入栏**:工具栏可换行;技能与数据源标签单行显示、过长省略,完整内容放在悬停提示;
   数据源标签由「数据源：本体：X」改为「数据源：本体「X」」。

## 后果 / Consequences

- 部署环境实测(108 表本体,12 条关系):连线经过无关对象框的点 0 个,经过文字的点 0 个,文字溢出框外 0 处。
- 依赖原字样的测试与集成检查同步更新;`_gate_category` 按「不在本体已验证关系」归类,不受措辞变化影响。

## 备选与不做 / Alternatives

- **关系图改用 G6 力导向布局**:不采用。问数结果卡里会同时出现多张图,内联 SVG 不依赖画布初始化,
  也便于历史回放;网格加通道走线足以避免穿框。
