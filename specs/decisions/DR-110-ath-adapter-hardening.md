# DR-110 · ATH 适配层加固

状态：已实现。日期：2026-11-14。
关联：ATH-HARDEN-01、DR-102、DR-104。来源：对适配层的一轮对抗性探测。

## 问题与处理

| 问题 | 处理 |
|---|---|
| 授权页的数据来源永远只有示例主库。`_sources()` 把 DataMind 的 `{sources, assets}` 当成列表读，取不到任何来源后回退到缺省值，「令牌限定数据来源」只对示例库有效 | 按实际返回结构读取；兼容直接返回列表的旧形态 |
| 审计日志 `audit.jsonl` 权限是 0644，与「状态目录文件均为 0600」的说明不符 | 以 0600 创建，每次写入时把旧文件一并收紧 |
| 口令可以无限次尝试 | 同一用户连续输错 5 次锁定 5 分钟（429 + `Retry-After`），锁定期内正确口令也不放行；成功登录清零 |
| DataMind 不可达、路径含空格或中文时资源接口返回未处理的 500 | 上游失败返回 502 `upstream_unavailable` 并记审计；转发前对路径重新做百分号编码 |
| 路径里编码过的 `?`、`#` 被解码后拼进上游地址，可以夹带查询参数 | 同上，重新编码后它们仍是路径的一部分 |
| MCP、A2A 的参数类型不对时返回 500 | 返回 JSON-RPC `-32602`（400）；没有 `id` 的通知执行后返回 204 |
| 元数据里的 `issuer` 取自请求的 Host 头 | 配置了 `DATAMIND_ATH_PUBLIC_URL` 时用它；否则只认适配层自己的回环地址 |
| 导出 Turtle 等非 JSON 内容时响应类型仍标成 JSON | 透传上游的 `Content-Type` |
| 没有令牌撤销与自省 | 新增 `POST /revoke`（RFC 7009）与 `POST /introspect`（RFC 7662），需客户端认证，只能操作发给自己的令牌 |
| 只读令牌经 `list_build_sources` 能看到其他数据来源的名称与表数 | 构建 MCP 服务在被限定来源时只列出该来源 |

## 没有改的

- 令牌仍在内存里，适配层只能单进程运行；锁定计数同样在内存里，重启后清零。
- 用户仍只有首次启动生成的一个，没有改口令的入口。
- 请求里的 `resource` 参数（RFC 8707）仍只记录、不校验。
