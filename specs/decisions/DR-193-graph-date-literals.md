# DR-193 · 图谱编辑副本的日期与日期时间数据值

状态：accepted。
实现交付状态：delivered。

## 上下文

[DR-190](DR-190-graph-relation-endpoints.md) 允许在编辑副本中为实例添加日期和日期时间数据值。服务端此前借助 Python 的 ISO 解析判定写法。这种判定会接受 XSD 不允许的写法，例如只写到小时的日期时间，或同时带时区偏移与 `Z` 的值；也会拒绝合法的带时区日期。项目支持 Python 3.10 及以上，3.11 起的解析更宽松，同一输入在不同运行环境下结果不同。无效值可经「保存为新版本」持久化。

## 决定

- 日期和日期时间按 XSD 词法逐项匹配，不依赖运行环境的日期解析。
  - 日期为 `YYYY-MM-DD`，日期时间为 `YYYY-MM-DDThh:mm:ss`，秒可带一位以上小数。
  - 两者都可带 `Z` 或 `±hh:mm` 时区，偏移范围为 `-14:00` 至 `+14:00`。
  - 日按所在年月的实际天数校验，含闰年。
  - 只接受 ASCII 数字。
- 基础编辑器只写入 0001 至 9999 年的值，不接受 `24:00:00`。这些写法在 XSD 中合法，但通用 RDF 读取端不能把它们转换为日期值。已有 RDF 中的这类值不受影响，仍可单独移除。
- 写法不符时，422 提示附带对应类型的正确示例。整数、小数和布尔值的判定不变。
