# DR-190 · 图谱关系端点与数据值校验

状态：accepted。
实现交付状态：delivered。

## 上下文

同一对实例可以通过不同的对象属性连接。新增连接时，起点和终点是否可选，取决于所选属性在当前副本中声明的定义域和值域。表单和写入接口须使用同一判定规则。

## 决定

在编辑副本中按关系的含义选择起点和终点。服务端每次以重放到当前步骤的 RDF 为准。只有显式声明的命名类别可以作为表单里的类别端点。

| 操作 | 起点 | 终点或值 |
|---|---|---|
| 实例关系 | 满足对象属性定义域的实例 | 满足该属性值域的实例。 |
| 继承 | 子类 | 父类。排除自己及已有的直接、间接子类，应用图使用已确认的类别映射判断循环。 |
| 实例归属 | 实例，包括未分类实例 | 已有类别。 |
| 属性定义域 | 对象属性或数据属性 | 已有类别。 |
| 属性值域 | 对象属性 | 已有类别。 |
| 属性值域 | 数据属性 | 已知的内建数据类型或显式声明的数据类型。 |
| 新增数据值 | 满足数据属性定义域的实例 | 符合值域的字面值。 |

继承沿用项目建模阶段的无环层次约定。互斥和等价仍允许以任一类别为起点，另一个不同的类别为终点。

数据值的定义域复用实例关系的类别判定。编辑器可写文本、整数、小数、布尔、日期、日期时间和带语言标签的文本。普通文本按字符串校验，带语言标签的文本按 `rdf:langString` 校验，整数也满足小数值域。多个值域须同时满足。缺少值域时沿用已有可写类型。有效的自定义数据类型可用于声明值域，基础表单仅在有可写类型时允许添加值。

在「新增关系 → 实例关系」中先选对象属性，再选起点和终点。起点须满足该属性当前的定义域，终点须满足值域。切换属性后重新计算两组候选。若任何一端没有可选实例，表单提示原因并禁用「应用」。

每一端独立判定。没有声明的一端可选择任意已有实例，包括未分类实例。命名类别接受显式归属该类、其子类或命名等价类的实例。固定应用版本沿用已确认的类别匹配。多个域声明须全部满足，一个匿名并集声明只需满足其中一项。所有实例均满足 `owl:Thing`。其他匿名表达式不能单独作为准入依据。

服务端在重放每次新增关系的操作时，从当时的副本 RDF 和固定版本的确认映射判定两个端点。起点或终点不符时返回 422 并指出哪一端不符。编辑视图和所有导出格式使用相同的写入校验。不符合当前属性声明的已有实例关系和历史继承环中的边仍可单独解除，不符合当前声明的旧数据值仍可移除。
