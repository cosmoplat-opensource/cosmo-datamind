# DR-131 · 重复计数检查按查询块判断，界面的失败态与转义，文档与当前界面对齐

> 2026-11-15：子查询别名的豁免、聚合内容的判断、数值匹配的两条规则和默认本体的范围已由 [DR-132](DR-132-shadowed-aliases-accessibility-terms.md) 修订；「没有做的」里的可访问性四项也在 DR-132 处理。

状态：已实现。日期：2026-11-15。
关联：QA-FANOUT-03、QA-STATUS-02、QA-SCOPE-02、ANSWER-RECORD-04、UI-SAFETY-01、UI-CHART-01、DATA-CONTEXT-01；DR-055、DR-122、DR-128、DR-129、DR-130。

## 背景

对本分支的改动和全部文档做了一轮复查，结果分三类。

**DR-130 的重复计数检查误拦了正确的查询。** 它把聚合括号里出现的每一列都当作被聚合的列，
并且在整条语句上判断，不区分子查询：

1. `SUM(CASE WHEN o.status = 'paid' THEN i.amount END)`、`SUM(i.qty * p.unit_price)` 被拦下。
   父表的列在这里只是条件或逐行的乘数，行粒度仍是子表，结果不会重复。
2. CTE 或标量子查询里对父表单独求和（占比类查询的分母）被算到外层的关联上。
3. `EXISTS`、`IN` 子查询里的等式被当成关联，半连接被判成「第二张子表」或「多对多」。
4. 自关联（员工 → 上级）按表名判断父侧，方向取反。
5. 同一张子表关联两次没有被拦下。
6. 拦截提示建议「先在子表按键聚合再 JOIN」，而 `JOIN (SELECT …) x` 这种写法会被连接键校验拒绝。

**其他缺陷。**

- 查询出错后经核对改写成功的、被拦下后仍按精确作答展示的，结果在答案里，却仍计为失败。
- 名字里带 time、date 的数值列（`downtime_minutes`）被当成时间列，依据卡上出现「实际取数截至 123456」。
- 只有一行且各列为空的汇总结果（`SUM` 没有命中任何行）被标为取到数据。
- 追踪没有校验状态表的范围，推演没有校验参数间接取值的表；库里不存在的表被说成「不在所选范围内」。
- 数字写在列名前面（「5300 元销售额」）、区间的两端（「13.83%–16.63%」）被报为张冠李戴。
- 界面：数据质量、术语请求失败时显示「全部检查通过」「共 0 条」；附件上传失败仍提示成功；
  表名、证据来源、技能对比的单元格没有转义就写进页面；三处内联处理器把转义后的文本放进 JS 字符串；
  列表接口返回错误时页面停在「加载中」；`--muted` 样式变量没有定义；动作中心五张指标卡排在四列网格里；
  动作结果未知时显示成功提示；「上传技能包」按钮不上传任何内容。
- 按「月份 × 区域」返回的长表被画成一条来回折返的线。
- 主库换成别的库以后，内置示例本体仍算作当前库的本体，并作为默认的问数本体，
  问数生成的 SQL 会引用不存在的列。
- 文档：快速入门的命令输出、界面文字和截图是 8 月的版本；安装说明里的启动与停止方式、日志位置、
  默认数据库、检查点数量与代码不符；架构说明漏列 11 个模块，两处路由数有误。

## 决定

- **按查询块判断**。括号里以 SELECT 或 WITH 开头的内容是一个查询块。关联、父侧别名、聚合各自归到所在的块，
  只在块内比较。子查询里的重复计数照样拦下。
- **只在聚合内容全部来自一张表时判断**。聚合括号里的列（带表名的，以及只有一张表有的不带表名的列）
  属于同一个别名时才检查；同时用到两张表的列时不拦。
- **父侧按键判断**。等式两边哪一列是父键，哪个别名就是父侧。同一个父侧别名下有两个子表别名即算互相放大，
  不要求是两张不同的表。
- **子查询的别名**。`FROM` / `JOIN (SELECT …) x` 的 `x` 和 CTE 一样对待，不做连接键校验。
- **查询状态**。执行出错后改写成功、被拦下后仍展示的查询不计为失败。
  时间列按名字里的整词识别，取值要像日期，第一个候选不是日期时换下一个。
  只有一行且各列为空的结果按空结果处理。按规则判定和异常汇总的答案不加空结果说明。
- **范围校验**。追踪加上状态表，推演加上参数间接取值的表；库里不存在的表不算「范围之外」。
- **数值匹配**。列名紧跟在数字后面时以它为准；区间的两端可以是结果里任何一行的值，但仍须有出处。
- **界面**。请求失败显示失败原因；写进页面的文本一律转义，内联处理器的参数用 `jsAttr`；
  列表接口统一经 `JL` 读取；删去不上传内容的「上传技能包」按钮；页面文字去掉开发备注，
  状态、级别、成熟度显示中文。这些写法由 `tests/meta/test_ui_safety.py` 约束。
- **图表**。横轴取值有重复且另有一个文字列时，按文字列拆成多条序列（`ui/modules/chart-series.js`）；
  分组超过 12 个时不拆。
- **默认本体**。没有登记数据源的内置本体，绑定的表一张都不在当前主库里时，不算当前库的本体；
  主库有自己的本体时用它作默认，没有时保持原来的回退。
- **文档**。快速入门按当前版本重走一遍后重写，截图重截；引擎设置的截图用本机的测试端点重截，
  不含真实密钥；安装说明、架构说明、教程按代码改正。

## 没有做的

- 聚合内容同时用到两张子表的列（`SUM(a.x * b.y)`）不拦。
- 不带表名又有两张表都有的列仍不判断。
- 空结果的核对、取数日期的查询在答案返回前同步执行，大表上会增加等待时间；没有做成异步。
- 界面上的弹窗没有做成对话框语义（焦点限制与返回），部分图标按钮和表格行不能用键盘操作，
  多处请求期间按钮没有置灰，小于 12 像素的字号没有调整。这些已列入待办，未在本次处理。
- 教程里 8 月的运行记录没有重跑，只标明了日期并改正了界面文字。
