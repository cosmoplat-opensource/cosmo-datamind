# DR-185 · 密集图谱布局期间保持交互响应

状态：accepted。
实现交付状态：delivered。

## 背景

浏览器验收覆盖 3 个类别、601 条连线的固定版本图谱。进入包含 401 条连线的局部范围后，Playwright 能找到「显示完整图谱」按钮，但点击超过 3.5 秒。降低 Chromium 的 CPU 速度可复现同一点击超时。
布局动画和拖动反复在主线程计算连线路径和标签避让，密集图谱上的重绘会占用处理输入的时间。

## 决定

节点移动期间沿用连线路由的偏移和已计算的标签相对位置，随连线更新标签和引线。动画结束、暂停或拖动结束时，按最终几何重新计算连线路径和标签避让。
尚无避让结果的标签暂贴在连线中点。密集范围在移动期间可能短暂重叠，静止后恢复按当前几何避让。
保留原有节点与连线上限、局部范围、搜索、固定节点和缩放行为。尝试恢复超限全图时，提示范围过大并保留当前局部图谱。验收沿用 3.5 秒的真实浏览器点击时限。

验收与复现见 [IR-046](../iterations/IR-046-interactive-graph-responsive-layout.md)。
