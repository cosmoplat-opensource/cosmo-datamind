# DR-047 · 侧边栏信息架构与字号层级

- **状态 / Status**: accepted
- **日期 / Date**: 2026-08-14
- **决策者 / Deciders**: Boss(用户,界面标注)+ Writer(Claude)
- **关联 / Refs**: [[DR-005-frontend-design-system]]、[[DR-007-url-hash-routing]];实证=`ui/index.html`、`tests/unit/test_ui_nav.py`、`test_ui.py`

## 上下文 / Context

用户在 2026-08-14 的界面标注上提了两条意见,红色箭头分别指向分组标题「智能问数」与菜单项「动作中心」:

1. **「菜单的样式有点乱」**
2. **「目录比菜单的字体还小,不清晰」**

逐项量化后确认三处成因:

| 成因 | 实测 |
|---|---|
| **内容字号倒挂** | 内容区 `table` 12.5px **小于**侧栏 `.nav` 14px —— 主内容比导航还难读 |
| **分组信号过弱** | 分组标题 11px、折叠箭头仅 **9px** 且 `#9aa4b2` 极淡;组间距 2px,上一组的项与下一组标题几乎贴合,层级读不出(标注截图里箭头小到看不见,一度被误认为「智能问数没有箭头」) |
| **归属混乱** | 本体相关 7 个页面**分散在两组**——`graph/build/claw/review/ontquality` 在「数据建模」,`library/sparql` 在「本体治理」;而「本体治理」组里还挂着**动作中心**(业务动作执行,与本体治理无关);术语管理埋在「智能问数」组内 |

## 决定 / Decision

1. **字号层级**:`table` 12.5→13.5px、窄屏 12→13px;`th` 加字重与浅底色;
   单元格**垂直** padding 6→8px 提升行高。
   **水平 padding 保持 8px 不动** —— 见「代价」一节。
2. **分组信号**:`.gh` 11→12px、`#9aa4b2`→`#64748b`;`.ar` 9→11px 并继承标题色;
   `.nav-group` 上间距 2→10px 且加顶部细分隔线;组内项左缩进 2→6px。
3. **信息架构重排**(10 组 → 9 组,27 个页面一个不少、`data-p` 全不变):

| 分组 | 页面 |
|---|---|
| (顶层) | 总览驾驶舱、数据可视化 |
| 数据资产 | 数据连接、数据目录、数仓分层 |
| **本体工程** | 本体图谱、本体构建、本体对话、本体评审、元数据覆盖、**本体库**、**SPARQL 查询** |
| 指标平台 | 指标中心、构成规则 |
| 数据治理 | 数据质量、**术语管理** |
| 智能问数 | 深度问数、业务助手、问数评测 |
| **智能体与技能** | 智能体列表、技能中心 |
| **动作执行** | 动作中心 |
| 开发与服务 | SQL 工作台、API 服务目录 |
| 运维管理 | 作业中心、引擎设置、系统管理 |

   要点:本体 7 项归一;**动作中心独立成组**(不再挂在本体分组下);术语管理归治理;
   智能体与技能合并;单页的「数据开发」与「数据服务」合并为「开发与服务」。

## 代价与边界 / Trade-offs

- **抬字号会撑宽表格**。首列表名 `white-space:nowrap`,13.5px 下长名(如 `DWS_ORG_PERFORMANCE_DAILY`)
  把末列「列」挤出 320px 容器(实测右边缘 571 > 容器 556;改动前 12.5px 时为 550 ≤ 556,可见)。
  **实施中一度把水平 padding 也加到 10px,使溢出再扩大 12px** —— 由新增断言当场抓出。
  终解:水平 padding 回到 8px + 目录页左栏 320→**360px**,两种视口下末列均回到可视区。
- 分组重排只动**归属与顺序**,不改 `data-p`、不增删页面,故 hash 深链(DR-007)与既有测试的按页走查全部不受影响。

## 影响 / Consequences

- (+) 内容字号不再小于导航;表头可辨;行高更舒展。
- (+) 分组边界、可折叠性一眼可见;同类页面不再分散两处。
- (+) 新增 `tests/unit/test_ui_nav.py`(8 条,静态解析 `ui/index.html`,无需起浏览器):
  字号层级、箭头可见性、组间距、页面数守恒、本体页归一、动作中心不在本体组、术语管理归治理、
  以及**水平 padding 上限**这条从本次回归中长出来的规则。
- (+) `test_ui.py` 增一条几何断言:目录表格末列须在可视区内(纯计数类断言看不出「被挤出去」)。
