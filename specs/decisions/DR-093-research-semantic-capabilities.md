# DR-093 · 将本体研究能力纳入产品，保留证据边界

日期：2026-10-11。状态：实现。验证报告：`.check-results/dr093-unit/`；HTTP 回归：`.check-results/dr093-integration/`。

## 依据与取舍

实验分支 `cosmo-datamind-exp` 提供了名称—取值目录、库内字段文档和从业务问题构建概念层的能力。近期比较同时表明，扩大概念清单并不保证提高问数成绩，同模型结果不足以证明本体在所有基准上具有独占优势。

本次移植可核验的产品能力，保留主仓三个候选投票、只读探查、本体约束、人工评审和完整值域判据。不采用实验分支较宽松的外键升级规则，不把尚无稳定收益的视觉机制并入默认产品流程。

## 实现与状态

- `data_catalog.py` 只读取真实表列，补入库内字段文档；名称—取值目录保留完整计数、实体覆盖、观察到的单位集合与目录截断状态。多单位不静默选一个。空值提示明确为有界抽样，缓存随来源库和 WAL 变化失效。
- 构建 API 增加可选 `workload` 字符串列表，最多处理 1000 条，分批提议；未提供业务问题不增加概念模型调用。无效、超限和未处理输入都有数量记录。同文 CQ 从概念提议输入排除。这不改变原构建链使用 CQ 对齐目标的既有行为，也不能自动识别改写后的重复问题。
- 概念过滤、主题代码与使用建议逐条在只读快照中检查，保存实际执行的完整 SQL。拒绝写入、堆叠语句和扩展加载；提议与核验受整体预算限制，超时任务在副本中运行，不修改已发布图谱。
- 查询有数据只支持取数绑定，不能证明模型写出的业务定义、汇总或提醒。这些条目保持 `candidate/not_reviewed`。派生公式仅检查输入概念，明确 `formula_verified=false`，不进入已验证指标数量。
- 概念别名参与表召回。同步和 SSE 问数共用相关概念/主题/公式上下文，受可执行表和显式选表边界限制。每类最多召回 8 项；已否决或失效绑定不进入提示。
- 继续构建时重新检查机器绑定：失效内容保留供复核并退出取数提示，同一绑定重新成立时可更新。多图谱合并保留同名但不同表的概念。人工决定不由自动提议覆盖。
- 本体评审展示概念、主题、公式建议和使用建议的绑定与证据。确认含义/否决要求评审人，否决要求原因，编辑日志可撤销。确认只产生 `asserted`，不把公式或查询升级为 `verified`。
- `declared_fk.py` 统一模型辅助与离线构建：复合键按 FK id 联合检查；完整约束检查通过且存在非空引用才可 verified；角色键独立保存证据。孤儿或零引用仍为候选。复核技能重读实际 DDL 和引用数据，模型的 declared 标记不能替代检查；键名争议保留为语义复核信号。
- 新阶段及提议数量接入观测，未确认语义进入质量评审清单。已有图谱不会被升级程序自动改写，须选择原图继续构建以补齐目录与重核验绑定。
