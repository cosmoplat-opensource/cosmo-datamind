# DR-069 · 本体应用中的行为树任务

## 上下文

用户要求行为树生成与深度问数成为同级应用，从机器人本体图谱直接创建任务，支持一个本体多次生成及历史查看。
任务会话和 generate_bt 运行已经持久化，但缺少应用首页和可发现的历史入口。

## 决定

1. 左侧导航“智能问数”改为“本体应用”，保留深度问数、业务助手、问数评测，新增可见的“行为树生成”。
2. 机器人关系图提供“基于此本体生成行为树”，固定当前本体版本；应用首页也可选择机器人本体创建新任务。
3. 复用现有任务会话与运行存储，不以本体 ID 作为任务唯一键，不新建平行历史数据库。
4. 左侧历史列表展示每份已生成结果，以及尚未完成的任务；显示任务描述、本体名称、版本、状态及时间。一个会话的多次成功生成按运行分别保留。
5. 生成历史按固定运行只读查看与下载，读取时校验 manifest、固定本体和工件；打开历史不调用模型、不生成新会话。未完成任务可继续。
6. 新任务不覆盖旧结果；历史结果提供“基于此本体新建任务”，使用该记录的固定版本。保留旧任务深链接。
7. 页面复用问数的历史侧栏、工作区、卡片及配色，支持搜索、加载更多、窄屏、空状态和错误提示。构建来源行为树仍不对用户开放。

## 后果

补充任务记录时间与生成描述快照；历史旧数据没有时间时如实显示旧记录，不伪造时间。
历史结果来源于既有运行及 XML 文件，与任务页当前结果分开寻址，避免后续修改覆盖历史视图。
本轮不增加任务删除、机器人执行或 XML 编辑。
