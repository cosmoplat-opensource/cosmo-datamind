# DR-176 · 回收站本体的固定版本图谱访问

状态：accepted。日期：2026-11-24。
实现交付状态：delivered。

## 背景

[DR-159](DR-159-pr1-review-fixes.md) 要求显式进入历史视图才能查看已删除本体的固定版本详情。详情中的图谱读取同一版本，也需要遵守这一约定。

## 决定

固定版本详情及其交互式图谱、关系图、行为树视图共用服务端生命周期检查。普通请求和 `state=active` 请求读取已删除本体时返回 HTTP 409 和 `ontology_deleted`。显式的 `state=deleted` 允许按原版本只读浏览。恢复后，普通入口重新可用。

沿用详情的参数契约，只接受单个 `state`，值为 `active` 或 `deleted`。历史浏览继续校验机器人领域、版本归属和来源完整性。回收站详情与图谱之间的往返链接保留历史上下文。

## 影响

保存了已删除本体普通图谱链接的调用方应从回收站重新进入，或在历史读取请求中显式携带 `state=deleted`。现有版本及其存储格式无需迁移。

对应 [IR-037](../iterations/IR-037-fixed-version-graph-lifecycle.md) 和 GRAPH-LIFE-01。
