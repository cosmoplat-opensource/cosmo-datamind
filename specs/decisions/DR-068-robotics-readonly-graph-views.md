# DR-068 · 机器人本体关系图与行为树视图

## 上下文

用户要求从本体库机器人卡片打开关系图，从本体详情打开行为树视图。
现有任务结果树属于一次生成运行，不适合作为本体版本的流程展示。

## 决定

1. 本体库机器人条目新增“打开图谱”；详情新增“打开行为树视图”，两者固定 ontology_id/version_id，显示名称与短版本编号。
2. 只读关系图投影当前 RDF 的命名实例、实例间关系和文字属性，不修改本体，不包含 OWL 类定义、匿名限制与审计事件。支持业务对象/技能流程/全部筛选、名称搜索、拖动缩放、节点详情。
3. 行为树视图使用当前 RDF 的流程/步骤/绑定重建，不读取原 XML 或调用 LLM；分树展示执行顺序、子树引用和节点参数。明确标注“本体流程 · 非任务生成结果”，不代表已适配或可执行。
4. 两种视图复用本地 G6 与现有页面设计；独立只读 GET 校验版本及来源完整性，失败展示错误，不使用旧版本兜底。
5. 限制单次投影规模，超限明确报错而非悄悄裁剪。保留原数据图谱、任务结果树和高级维护入口。
6. 数据流画布、拖拽编辑、XML 编辑与实机执行不属于本轮。

## 后果

视图不会产生新版本、任务或运行记录；刷新和切换页面不触发模型与写入。
本体行为树显示存储的流程绑定，具体任务的参数仍以生成结果为准。
