# DR-183 · 首次打开超出同屏上限的机器人图谱

状态：accepted。
实现交付状态：delivered。

## 背景

首次打开含 301 个互不相连类别的图谱时，页面提示缩小范围，但「节点详情」里没有可选类别，搜索也找不到对象。控制器沿用了替换已有修订时的回退逻辑，连同尚未显示的画布一起丢弃了首次收到的对象索引。

## 决定

首次投影超过 300 个节点或 600 条连线时，保留当前文档的修订身份和对象索引，画布显示零个节点，并提示从类别进入局部图谱。读者可以在「节点详情」中选择类别，也可以按名称查找类别。局部视图和恢复完整图谱都遵守同屏上限。请求的范围过大时保留原有画布与范围，读者可以继续选择其他类别。

同一上下文已有可浏览的修订时继续遵循 [DR-167](DR-167-interactive-graph-limits-and-publication-boundary.md) 的修订替换规则。验收与复现见 [IR-044](../iterations/IR-044-initial-graph-class-scope.md)。
