# DR-167 · 应用检查的易懂提示与返回导航

状态：accepted。日期：2026-11-19。依据：维护者要求说明缺少的内容和解决办法、合并修复入口，并排查后退后操作失效的问题。
实现交付状态：delivered。

## 决定

机器人应用检查优先显示业务含义、缺项影响及下一步操作，技术标识、类型约束与原始诊断保留在可展开详情中，不删除检查证据。
默认只显示一个“完善本体”入口；受控词表中的定义缺项优先修订，未知或自定义词表优先核对已有定义，不能根据相似标签自动确认对应关系。
已有修复动作及服务端约束保留，默认展示顺序由服务端依据冻结词表决定，其余处理方式折叠保留。
当前检查所发起的修复在返回浏览器历史时重新检查，并停留在诊断页供用户操作，不自动再次修复或创建任务。
返回标记按检查编号、本体固定版本、模式和任务限定；外部变更导致的旧报告仍保持过期保护，不能直接将禁用按钮强行启用。
提交期间阻止重复操作，成功导航、失败和迟到响应均不能留下永久禁用状态。
修复导航请求在 30 秒后超时并解锁，显式重试复用请求编号，不自动重复提交；原任务已更换版本时提供显式的当前任务入口，不绕过固定版本身份检查。
对任务内嵌检查、适配、构建、历史与版本浏览排查同类导航问题；只修复有证据的问题，不做全站无关重构。

## 兼容与影响

不改变应用判定、角色匹配、执行资格、模式隔离或持久化结构。
报告继续保留原有动作编号和诊断字段；修复动作列表首项表示推荐路径，自定义来源的顺序可与旧版本不同。
检查上下文新增冻结词表摘要，旧报告可能显示过期，重新检查后再继续；历史报告内容不改写。
对应 [IR-033](../iterations/IR-033-application-guidance-and-return-navigation.md) 和 `specs/acceptance.json`。
