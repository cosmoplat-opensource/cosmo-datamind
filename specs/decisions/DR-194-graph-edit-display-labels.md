# DR-194 · 图谱编辑副本沿用显示名称

状态：accepted。
实现交付状态：delivered。

## 上下文

[DR-148](DR-148-minimal-robotics-task-workflow.md) 规定旧版配置名称在界面中按统一名称显示，不改写固定版本中的 OWL 字节。机器人图谱页面只对首次读取的固定版本视图做了这一转换。进入「编辑副本」后，编辑接口返回的视图直接显示，旧名称（例如带"尚未绑定"字样的配置名称）重新出现；返回原图后又恢复统一名称。

## 决定

- 机器人图谱页面用同一个转换处理固定版本视图和编辑副本返回的视图，覆盖类别和实例的标签，以及实例的 `rdfs:label` 数据值。
- 转换只改显示文本。显示文本与原文不同时，条目保留原文 `raw_value`。
- 编辑器在「编辑实体」中以原文预填中文名称，删除数据值时按原文匹配。未修改名称时不会把显示名称写回本体。
- 编辑接口、导出内容和保存的版本不变。
