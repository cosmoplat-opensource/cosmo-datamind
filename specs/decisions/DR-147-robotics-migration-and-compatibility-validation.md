## 上下文 / Context

本次复测 agent 的 7 个测试脚本通过，构建侧 3 个脚本通过，但跨目录 ontology-only 测试因同名 skill_runtime 混用失败。
新构建 OWL 与 agent 预置 OWL 不满足同一发布契约，不能只测试预置产物证明前后段已联通。
两份运行时在参数定位、条件定义与不完整草稿策略上已经分叉，直接去重可能改变生成语义。
DataMind 与源项目虚拟环境使用的 pySHACL 版本不同，原环境测试通过不等于迁入环境兼容。
原计划经 Graph v2 再回 OWL 的双重转换增加风险，并不是本次集成必经步骤。

## 决定 / Decision

1. **冻结事实基线**：保存来源 XML、节点模型、两侧真实 OWL、演示 OWL、任务用例与代表报告，分别标记已通过行为和已知缺陷。
2. **先对齐契约**：首个技术里程碑验证本轮新来源构建、发布封装与 agent 加载，不能用预置 OWL 替代新产物。
3. **显式包化**：消除 sys.path 注入和同名顶层模块，先对照两侧行为，再合并共享语义读取、绑定与校验逻辑。
4. **保留策略差异**：严格生成的拒绝条件和作者草稿的未解决值行为分别定义与测试，不以修改旧断言掩盖不明确的产品语义。
5. **迁移保持 RDF**：先由版本化 RDF/OWL 驱动迁入的确定性编译器，不要求 Graph v2 转换；通用图表示的替换另立规约。
6. **比较语义而非排版**：核对 RDF 图同构及领域断言、树次序、调用身份、端口类型、参数位置、黑板作用域、澄清状态和校验结论，文件摘要另用于完整性。
7. **完整用户链验收**：使用新构建本体与显式演示补充资料跑通平台构建、评审发布、任务和候选下载；真实资料缺证据时继续返回 needs_information。
8. **负向行为守住**：未知任务、歧义实体、缺少证据、模式混用、模板漂移、规则篡改、模型失败、来源变更及路径越界均有预期结论。
9. **统一环境回归**：在最终选定依赖环境运行机器人兼容测试和 DataMind 相关回归，最终实施交付再按 SDD 执行全量检查。
10. **渐进切片与回退**：按方案步骤创建 IR、验收映射与失败用例，领域开关可撤回新入口而不破坏既有数据图谱及数据应用。
11. **复用能力需要回归保护**：验证旧对话历史仍可读取、新会话可关联多次运行、manifest 与固定版本及文件摘要一致，以及首版视图可解释调用和参数来源。
12. **知识映射不越权升级**：测试用户澄清不会自动确认永久映射或适配证据，同名跨域对象不被自动合并，模板步骤不会随模型输出任意重排。

## 后果 / Consequences

- 正面影响：优先暴露构建到消费的真实断点，迁移成败可由语义和用户流程判断。
- 正面影响：原有拒绝策略、草稿能力和数据平台能力都有明确的回归边界。
- 代价：需要维护兼容夹具、跨包行为对照与选定依赖环境的验证记录。
- 代价：本次脚本通过记录不等于集成验收；现场设备执行和真实模型效果需要另行验证。
- 影响的文件/路由：机器人包导入、发布器、迁移适配、tests/unit、集成测试、浏览器测试、后续 IR 与 acceptance 映射。
