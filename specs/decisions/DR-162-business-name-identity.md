# DR-162 · 业务名称落到确定的实体

状态：accepted。日期：2026-11-23。依据：多语言业务名称检索审计确认的缺陷（本地审计材料，按 DR-160 不入库），验收标准 DISC-* 见 `specs/acceptance.json`。

## 决定

- **SQLite 系统表只排除 `sqlite_` 前缀。** 各处 `NOT LIKE 'sqlite_%'` 中的 `_` 是 LIKE 通配符，会把 `sqliteLedger` 一类业务表一并排除；统一改为 `NOT LIKE 'sqlite\_%' ESCAPE '\'`。
- **上传分隔符按 CSV 规则判定。** 引号内的逗号不算列边界；按各候选分隔符解析前几行，列数一致且多于一列者胜出，默认分隔符优先。
- **重名不替人挑。** 按中文名、表名或别名定位对象，同一轮命中多个对象时报错并列出主键；指标先按主键、再按名称定位，名称被多个指标共用时返回 409。图谱节点详情、指标契约、状态与溯源都先按主键解析，前端点行时传指标主键。
- **全角标点按业务文本处理。** 别名接受全角逗号、分号作分隔；问句拆分、单位括号的正则恢复被误改为半角的全角字符（`，；！？（）`）。
- **单字业务名可检索。** 名称与整句检索词完全相同时命中，不受“至少两字”的子串规则限制。
- **非 ASCII 表名可问数。** 绑定表只要在数据库中真实存在即计入可查询范围，计数 SQL 按标准规则加引号。
- **RDF 标识不随排列顺序变化。** 转写有损的本地名一律附原名摘要；关系 IRI 只在完全相同的“源 + 动词 + 目标”之间编号，不再使用列表下标。字符全部保留的名称（含数字开头只补前缀的）IRI 不变。
- **同名数据源可区分。** 全局、SQL 工作台、可视化的数据库下拉框中，重名项附文件名，仍相同则附连接编号。
- **表单都有可读名称，窄屏不横向溢出。** 缺少标签的下拉框、输入框补 `aria-label`；480 px 以下顶栏收起快捷入口与头像，写死宽度的控件收进容器，按最小列宽排布的卡片网格改单列，引擎设置的表格在自身范围内滚动。

## 验收与恢复

需求 DISC-* 对应 `tests/unit/test_business_name_discovery.py` 与 `tests/frontend/business_name_browser.py`。复现：`python -m pytest tests/unit/test_business_name_discovery.py tests/frontend/business_name_browser.py`，以及 `python scripts/check.py --suite unit`。

兼容性：名称含空格、连字符等被替换字符的对象，导出 IRI 增加摘要后缀；同一对节点之间关系的编号改为按三元组计数。按重名的中文名、别名或指标名操作的调用改为得到错误与候选主键，需改用主键。回退时撤销本次提交即可，不涉及数据迁移。
