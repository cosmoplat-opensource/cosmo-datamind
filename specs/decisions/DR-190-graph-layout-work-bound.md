# DR-190 · 交互式图谱布局在同屏上限内的计算量

状态：accepted。
实现交付状态：delivered。

## 上下文

[DR-167](DR-167-interactive-graph-limits-and-publication-boundary.md) 把同屏规模限制在 300 个节点、600 条连线。在这个规模下，布局静止后的连线避让和连线标签排布都要全量扫描：每条候选曲线都要与所有节点、所有已布线的连线逐一比较，每个标签候选位置都要与所有节点、已放置标签和全部连线线段比较。

修复前，静止后的一次完整布局要阻塞页面约 1.8 秒。点击选中节点、切换语言等重绘不改变任何几何输入，却每次都重新排布全部标签，接近上限时每次点击约阻塞 0.4～0.5 秒。

## 决定

- 连线避让和标签排布使用均匀网格（单元边长 64）索引节点外框、连线线段和已放置标签。只比较外框可能相交的对象，跳过的都是原实现中必然得零分或被外框预检排除的组合。
- 结果与修复前逐位一致：罚分按原来的逐次累加方式计算，面积和交叉长度按原来的对象顺序求和，提前结束和并列取舍不变。坐标中出现非有限值时退回全量扫描。
- 标签排布只依赖连线、节点外框和标签尺寸。这些输入都不变时，重绘直接沿用已排好的标签位置，不再重新计算。节点移动、尺寸变化、连线变化或标签尺寸变化时重新排布。
- 布局函数可选输出比较次数，用于确定性地约束计算量。测试不对耗时做断言，耗时对比单独记录。
