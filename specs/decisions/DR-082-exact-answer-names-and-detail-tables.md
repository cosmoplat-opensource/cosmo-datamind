# DR-082 · 精确作答只返回所问名称、明细表优先;双向与工业库重复实验

## 上下文 / Context

DR-081 的对比只有 BIRD 一个方向、每个条件一次运行。本轮补齐三项:
BIRD 反向划分(测试题数翻倍)、每个条件重复 3 次、在 108 表与 200 表两个工业库上重复对比。

工业库问数题集在任何方法运行前生成并冻结:按七类模板从声明外键与字典中写明的外键生成标准 SQL,
由模型改写为中文问题,再由另一个模型核对问题与 SQL 是否一一对应(108 表 289 题、200 表 297 题),
按与 BIRD 相同的协议划分两个方向。

工业库验证集上 DataMind 问数的两类主要错误:
- 问「哪个/哪位/是什么」时,SELECT 同时返回了排序用的合计值,结果与只含名称的答案不相等;
- 明细事实表与汇总层表(`DWS_*`)都有相关列时选了汇总层表,两者数值不完全一致。

## 决定 / Decision

精确作答规则(`_EXACT_RULES`)增加两条,报告式作答不变:
1. 问「哪个/哪位/哪条/是什么」时,SELECT 只放所问对象的名称一列,排序用的合计值不放进 SELECT;
2. 明细事实表与汇总层表(`DWS_`、`agg_` 开头)都能回答时,从明细事实表计算;汇总层表只用于问题明确问汇总指标的情况。

方法选择只用验证集:

| 验证集 | D3 | D4(本决定) | C3 | H4(C3 + D4 投票) |
|---|---|---|---|---|
| BIRD(249 题) | 108 | 113 | 118 | **130** |
| 工业库正向(87 题) | 70 | 73 | 73 | **74** |

据此在看测试集之前确定最终方法为 H4,D4 作为 DataMind 单系统结果一并报告。

## 后果 / Consequences

测试集,两个方向合并,3 次重复的均值(逐次配对 McNemar 对 EvoOntology 条件 B):

| | BIRD(500 题) | 工业库(586 题) |
|---|---|---|
| B EvoOntology | 44.5% | 84.9% |
| D4 DataMind 问数 | 43.5%(不显著) | **89.3%**(3 次均 p ≤ 0.023) |
| H4 跨方法投票 | **48.7%**(3 次均 p ≤ 0.008) | 86.0%(不显著) |

- BIRD 上单系统仍与 ReAct 智能体相当,优势来自跨方法投票;工业库上 DataMind 单系统最好,投票反被 C3 拉低。
- 两条规则只对精确作答生效,产品默认的报告式作答不受影响。
- 实验分支在独立工作树中运行,D3 的全部重复使用同一提交,D4 与 D3 的代码只差本决定。
