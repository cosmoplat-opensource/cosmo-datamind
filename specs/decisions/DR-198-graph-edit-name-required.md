# DR-198 · 编辑实体时中文名称必填

状态：accepted。
实现交付状态：delivered。

## 上下文

[DR-188](DR-188-graph-edit-copy.md) 的「新增」要求填写名称，「编辑实体」却允许中文名称为空。名称清空后应用，会删除实体的中文标签，与新增时的规则不一致，而且用户可能是误操作。

## 决定

- 「编辑实体」的中文名称为必填项。为空时浏览器阻止提交，不发送编辑请求，对话框保持打开。
- 服务端在编辑操作中拒绝空白名称，返回 422，提示填写中文名称，副本不变。直接调用接口的请求同样受此约束。
- 说明仍可清空，清空即移除中文说明。
- 原本没有中文标签的实体，编辑时需要补填中文名称。
