# DR-174 · 公开规约中的版本与验证记录

状态：accepted。日期：2026-11-24。
实现交付状态：delivered。

## 背景

待公开材料中仍有外部来源的内部包路径、交付操作记录和用于标识历史验证的 Git 提交号。

## 决定

公开规约保留产品范围、验收标准、验证环境及可执行检查。历史验证按日期和变更范围分别记录，保留当时的结果与未验证范围。具体 Git 提交号、提交授权、单次重跑审批、服务操作和原始运行明细留在内部记录或 CI。

读者需要自行生成结果时，给出仓库命令、输入和输出位置。外部来源使用中性标识，保留文件摘要和提取规则，内部目录和原始清单留作内部追溯。公开用例说明可复核的行为，在读者检出的版本上生成新的结果。

任务配置与重试使用临时存储、合成输入及仓库测试复现。运维文档可以说明服务管理命令，产品规约可以说明业务表单提交、事务回滚和部署条件。

关联 [DR-160](DR-160-product-repository-material-boundary.md) 和 [IR-040](../iterations/IR-040-public-verification-records.md)。
