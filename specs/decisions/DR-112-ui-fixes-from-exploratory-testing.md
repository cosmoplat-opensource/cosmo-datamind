# DR-112 · 探索性测试查出的界面缺陷

状态：已实现。日期：2026-11-14。
关联：UI-FIX-03、DR-107、DR-043。来源：18 个页面在三种宽度下的扫描和逐控件点击。

| 问题 | 处理 |
|---|---|
| 评审页的弹窗挂在页面最外层，切到别的页面后仍留在屏幕上挡住操作 | 切页时关掉所有弹窗 |
| 没有可撤销的操作时「撤销上一步」仍可点，点了报错 | 评审接口返回可撤销的步数，为 0 时按钮禁用 |
| 评审页一上来是上百行对象和红色的「删除」按钮，排在关系评审前面 | 对象表默认折叠，有候选对象待确认时才展开；删除按钮不再标红 |
| 窄屏下菜单占满首屏，内容在下面 | 820 像素以下菜单默认收起，只留数据库切换；顶栏「菜单」按钮展开，选中页面后自动收起 |
| 不理会系统的「减少动态效果」设置 | 该设置开启时关闭动画与过渡 |
| 上传的文件只存档未建表时界面没有提示 | 上传成功的提示里带出仅存档的文件数 |

没有做深色模式：平台的配色令牌只有浅色一套。
