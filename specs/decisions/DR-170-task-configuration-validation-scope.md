# DR-170 · 按最终任务配置校验与生成

状态：accepted。日期：2026-11-20。依据：维护者明确任务适配阶段切换后未补全的旧配置不应阻断当前最终配置生成。
实现交付状态：delivered。

## 决定

任务适配按最终关联的感知、放置配置及其关节值、目标位姿依赖校验；未选中的草稿配置可以继续保留，不要求用户为其进入本体完善。
在完整原图上限定配置类校验的目标节点，不删除三元组、不丢弃失败报告、不填入默认参数或自动确认知识。
执行结构、技能参数、端口、绑定、数据流、固定版本字节、模式隔离及可信规则检查继续执行；共享依赖只要被当前配置引用就必须通过检查。
任务加载与生成时使用同一冻结任务范围，并拒绝将上下文复用于另一个任务。
任务验证报告明确标注配置范围，原始图和原始字节摘要保留；本体发布及默认完整消费校验仍检查全本体，任务候选不表示整个本体可发布。
在任务阶段发现当前配置缺项时继续原补齐表单；旧生成错误提供按当前配置重试入口，重试不重复调用模型、不自动改写原版本或确认状态。

## 关联与兼容

本记录替代 [DR-169](DR-169-single-repair-entry-and-generation-feedback.md) 中将未选中配置缺项作为任务生成阻断的决定，其余单一完善入口及真实错误提示保持。
现有完整加载调用保持默认语义；为任务加载增加可选 task 上下文及验证范围字段，调用方明确传入，既有发布规则和持久化结构不变。
对应 [IR-036](../iterations/IR-036-task-configuration-validation-scope.md) 与 CFG-SCOPE-01、GEN-FEEDBACK-01。
