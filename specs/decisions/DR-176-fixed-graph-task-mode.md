# DR-176 · 从固定版本图谱进入任务时保留模式

状态：accepted。
实现交付状态：delivered。

## 背景

同一份打包演示本体从关系图进入任务时使用演示模式，从交互式图谱进入时却使用真实模式。固定版本图谱响应缺少模式，页面构造任务链接时又沿用了真实模式默认值。本体和版本编号仍然正确，仅验证编号无法发现应用检查使用了错误的模式。

## 决定

固定版本交互式图谱响应增加顶层 `mode` 字段。服务端沿用固定版本的模式判定顺序：先取发布模式，其次取版本元数据。旧版本缺少两者时使用该版本 RDF 的演示标记，普通本体沿用真实模式。

活动版本的任务入口将服务端返回的 `demo` 或 `real` 连同本体和版本编号传给应用检查。如果响应未提供有效模式，页面仅展示图谱。回收站的历史图谱仍只读。任务服务继续独立校验模式和本体内容。
