# DR-191 · 图谱编辑副本保存为新版本

状态：accepted。
实现交付状态：delivered。

固定版本上的多次编辑可作为同一本体的新候选版本保留。「保存为新版本」以当前撤销位置为界，服务端从指定父版本的完整 RDF 重放操作，沿用编辑校验。预览、撤销、重做和文件导出继续在临时副本中进行。

新候选记录父版本并使用独立的版本标识和本体文件。原版本的字节、发布记录和固定版本引用继续有效。图谱保存独立于评审工作头及进行中的应用适配。设计或应用版本派生的图谱候选保留来源关系，有效的应用类别映射随候选保留。应用版本中的原始 XML 来源可通过父版本追溯。新候选引用仍需校验的附件。构建报告和发布结论归属于产生它们的版本。

在同一父版本上重试相同的有序操作时返回已保存的候选。写入失败时保留当前编辑内容。成功后打开新版本的图谱，可从该版本继续编辑。

活动机器人本体有两个及以上登记版本时，目录卡片提供「版本列表」入口。列表在独立弹窗中按版本倒序显示，内容超出可用高度时在弹窗内滚动。关闭后焦点返回入口。只有一个版本时，可直接通过「打开图谱」访问。
