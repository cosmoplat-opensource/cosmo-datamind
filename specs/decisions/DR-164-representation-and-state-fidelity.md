# DR-164 · 数值表示、状态切换与界面状态如实

状态：accepted。日期：2026-11-23。依据：此前两轮审计以 TDD 方式提交、产品尚未修复的验收用例（`tests/unit/test_representation_fidelity.py`、`tests/unit/test_state_transitions.py`、`tests/frontend/representation_fidelity_browser.py`、`tests/frontend/state_transition_browser.py`、`tests/frontend/navigation_transitions.py`）。修复后分支 CI 才能转绿并合入 master。

## 决定

**数据如实**
- SQLite 表名可以是中文、带空格或引号：详情、基本信息与预览只要求库内确有此表，SQL 中一律经 `_quote_ident` 加引号；外部库预览仍用标识符白名单。
- 列数含生成列：用 `PRAGMA table_xinfo`，排除虚表的隐藏列。
- SQL 工作台与图表取数超过行数上限时返回 `truncated`，界面注明“仅取前 N 行”；外部 MySQL/PostgreSQL 同样标记。
- 超过 ±(2^53−1) 的整数以十进制字符串返回，避免浏览器按双精度解析改成相邻值；表格按 15 位有效数字显示小数；NULL 显示为“NULL”，与空字符串区分。
- 外部库定点数在 float 能精确表示时保留数值，否则返回原样十进制字符串；二进制字段以 `0x` 十六进制给出。
- RDF 导出全部字段（取消 60 个的截断）；“对象_列”拼名在全图重名时改用双下划线，避免两个字段并成一个。

**状态不丢**
- 数据源与看板达到上限（30 / 50）时拒绝新登记并提示，不再悄悄删除最早的一项；抽样库在已满时生成但不登记，并如实说明。
- 本体对话写回时重读最新会话、只追加本轮消息；作答期间被删除的会话不复活。

**界面状态**
- 看板 KPI 卡与取数预览一样注明取的是哪一行。
- SQL 工作台结果注明来源库，切换数据源后旧结果不会被误认成新库的。
- 动作记录、问数评测、看板列表、本体对话会话列表在服务出错时显示“加载失败”，不显示成空列表；新建、清空会话失败时保留原记录并提示。
- 元数据质量页切换图谱时移除上一张图的语义评审计数。
- 菜单当前项设 `aria-current="page"`；看板数据源与 SQL 工作台一致可选外部实连库。
- 窄屏下收起的侧栏（含数据库切换）不显示且设为 `inert`，不抢键盘焦点；展开菜单后可用。

## 兼容性

API 只增加字段（`truncated`）或改变边界情况的取值类型（超大整数、不可精确表示的定点数为字符串，二进制为 `0x` 十六进制）。达到上限时新增 409 响应。导出 IRI 仅在“对象_列”重名时变化。回退时撤销本次提交即可。
