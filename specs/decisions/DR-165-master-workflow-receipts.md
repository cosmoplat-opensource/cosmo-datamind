# DR-165 · 数据源归属、动作回执与前端选择

日期 2026-11-24。状态 accepted。

- API 连接以成功取数时登记的独占物理表判断就绪。新连接首次写入时避开现有表和上传文件。删除后重建的同名连接需要重新取数。源响应的行列总数覆盖全部记录，导入继续限制为前 5000 行和 40 列。
- 待审批、执行中和结果待核对的动作一直保留，可从列表处置。另保留最近 1000 条已了结回执，手工处置按更新时间计入。
- 图表用选中指标的 ID 获取契约，保留仅有名称的旧指标兼容路径。较早的响应不能改写当前选择的 SQL。
- 问数选表时，全表复选框与每张表的按下状态随选择同步。鼠标、键盘和辅助技术读取同一状态。

逐项验收见 `specs/acceptance.json` 中的九项 `MASTER-*` 规格。班次场景以同名指标分别验算东区 90、西区 33。
