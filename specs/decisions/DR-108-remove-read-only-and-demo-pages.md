# DR-108 · 去掉五个只读或演示性质的页面和一条无调用方的路由

状态：已实现。日期：2026-11-14。
关联：UI-PRUNE-01、DR-007；来源为 2026-11-12 代码审查。

## 背景

侧栏有 27 个页面。其中一部分与本体构建、评审、问数的主流程无关，或者重复了别处已有的内容。
页面越多，新人越难找到主流程，每次改全站样式和走查也要多覆盖一批没人用的页面。

## 决定

去掉以下页面，连同它们的导航项、加载函数和页面走查：

| 页面 | 原因 |
|---|---|
| 数仓分层 | 按表名前缀分组，数据目录的筛选标签已经提供；标题里写死了「108 张表」 |
| API 服务目录 | 只读的路由列表，面向开发者；接口 `/api/routes` 保留，脚本仍在用 |
| 系统管理 | 只读的几项状态，与引擎设置重复；接口 `/api/sysinfo` 保留 |
| 智能体列表 | 只读表格，内容是问数技能和构建技能，这两者在问数页和构建页里各有管理入口；接口 `/api/agents` 保留 |
| 业务助手 | 角色、常用问题、动作都是写死的演示数据，点击后只是跳到问数页或动作中心 |

去掉路由 `GET /api/metric/dimensions`：界面、测试、脚本、文档都没有调用方，
它返回的可用维度已经包含在 `GET /api/metric/contract` 的响应里。

页面数 27 → 22，路由数 141 → 140。访问已去掉页面的旧地址（如 `#assistant`）会落到总览页。

## 这次没有去掉的

下列候选有集成测试、脚本或其他功能在用，去掉它们是产品取舍，留待确认：

- 页面：本体库（管理锻造的本体版本）、技能中心（可带参数运行技能脚本）、作业中心（展示技能运行和 `/api/build/run` 的后台作业）、构成规则。
- 路由：`/api/build/run`（已被 `/api/build/jobs` 取代，但有数据来源相关的验收测试在用）、
  `/api/ont/save`、`/api/ont/forge`、`/api/ont/rebuild`、`/api/ont/skills/write`、`/api/eval/set`、
  `/api/outputs`、`/api/outputs/file`、`/doc/<name>`、`/api/viz/delete`、`/api/skill/run`，
  以及本体治理的一组接口（能力问题、漂移、健康、兼容、模块化、规则库），界面没有接入，但集成套件在验证。
