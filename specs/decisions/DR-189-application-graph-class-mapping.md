# DR-189 · 在应用图中合并展示已匹配的类别

状态：accepted。
实现交付状态：delivered。

## 上下文

应用适配会保留设计类别的声明，同时使用应用词表中的对应类别。两个类别可以有不同的 IRI 和相同的中文名称。逐个绘制时，用户看到两个蓝圈，新增实例时也会遇到两个同名选项。

## 决定

固定应用版本及其编辑副本根据该版本应用工件中已确认的类别角色映射展示一个蓝圈。两端均有类别声明时，以应用侧 IRI 作为画布标识。缺少对应关系的类别各自展示。遇到标识交叉、不能唯一归属的映射时，保留相关节点并提示原因。

类别详情列出应用与设计 IRI。聚合的实例按实例 IRI 去重，类别关系按展示后的起点、谓词、终点及关系种类去重。对象属性和数据属性各自保留原有标识。选择合并后的类别创建实例时，将实例归入应用类别。

实体编辑或删除可选择原始类别标识。解除关系时按底层显式断言操作。一条可视连线对应多个显式断言时，按原始端点区分操作入口。导出使用编辑副本的完整 RDF，保留来源和应用身份。

图谱响应中的类别节点通过 `design_classes` 提供原设计类别的标识和说明。编辑视图中，归并后的 `types`、`domains`、`ranges` 可通过对应的 `original_types`、`original_domains`、`original_ranges` 找到显式声明。类别公理连线通过 `assertion_pairs` 区分原始端点。客户端提交解除操作时使用原始标识。
