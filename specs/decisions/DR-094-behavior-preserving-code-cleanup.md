# DR-094 · 保持正常功能的代码清理与重启配置检查

状态：已实现。日期：2026-10-12。
关联：DEP-01、DR-057、DR-093；[复核报告](../../docs/audits/2026-10-12-code-cleanup.md)。

## 上下文

前后端存在未被调用的私有辅助函数、空初始化函数和未使用的界面常量。
此次清理以工作开始时的源码快照为参照，保留已有研究能力、页面交互、接口和运行数据。
Flask 装饰器注册的函数、HTML 内联事件和独立 MCP 入口不能按文本引用次数判为无用代码。

部署管理器原先先停止服务，再读取重启配置。
环境文件格式错误或数据库路径不存在时，重启请求会使原有服务中断。
两个错误配置用例先复现失败，再调整检查顺序。

## 决定

- 仅删除确认无运行引用的四个私有函数、四个前端常量、一个未使用的计算、空初始化函数及调用、未使用的 CSS 规则和冗余异常类型。
- 保留公开辅助函数、动态注册入口、外部工具可调用的代码和独立进程所需的重复实现。
- 重启先解析环境配置并检查数据库文件，再执行原有的停止、启动流程；正常配置的目标和执行顺序不变。
- UI 种类名称测试改用仍有效的代码边界定位，保持原有标签断言；同时在清理前快照上验证测试。
- 对照接口、响应样本、剩余后端 AST 和静态页面结构，再运行离线回归及实际部署检查；不以一次静态扫描作为功能不变的证据。

## 后果

137 个路由、34 组受控响应样本和静态页面结构一致。
修订后 1252 项单元测试、45 项场景回归通过，确定性模块覆盖率 89.0%。
HTTP 集成 551 通过、8 条件跳过；十轮回归 10/10；页面走查 64 通过，UI 实操 50 通过、3 条件跳过。
实际部署 HTTP 检查 58/58，上传及错误恢复 9/9；实际页面走查与截图见报告。
错误重启的实际测试保持同一服务 PID；42 个受保护数据文件哈希不变。
正常功能未在这些检查中发现回归；错误配置导致停服的行为已修正。

首次清理回归暴露了一个依赖已删除常量的测试定位问题，失败记录予以保留。
可选上游引擎、真实模型调用、外部业务数据库及公网反向代理未作完整实连验证，不将条件跳过计为通过。
