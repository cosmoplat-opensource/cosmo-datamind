# 机器人交互式本体图谱 — DR-161 / IR-031

机器人建模工作区使用交互式本体图谱展示已保存的设计。
类别生成后出现蓝色圆圈；确认类别并设计关系与属性后增加连接；完成实例构建后读取对应固定版本，并在类别上显示显式实例数量。
等待和失败状态使用真实构建状态，不以动画模拟新增实体。

默认保持可读字号，可平移查看其它区域；“适应画布”显示全图，“可读视图”恢复阅读缩放。
拖动节点可带动其它未固定节点，松开后该节点固定；详情中可释放，也可暂停整个布局。
单击类别或连线查看定义和属性，双击类别展开／收起实例；默认每批 50 个，可继续显示或翻页至最后一个实例。
实例详情可查看真实关系和数据值，类别关联筛选可缩小密集图范围。
默认收起属性类型以便阅读，工具栏可展开属性类型。
空类别或尚未构建实例时显示说明，实例数量不包含推理得到的父类成员。

“设计修订”切换历史画布及历史定义，历史状态不提供阶段确认或建模发送操作，切回当前设计后可继续建模。
输入建模意见、拖动、搜索、展开和历史查看都不自动确认本体或调用模型。
已保存本体从目录“打开图谱”进入统一类别／实例画布，详情与行为树应用仍沿用固定版本规则。
原 `view=relations` 深链保留旧实例视图兼容，默认目录入口使用 `view=interactive-ontology-graph`；来源行为树不作为交互式本体图谱展示。
交互式图谱当前仅支持机器人本体。数据本体维持原有可视化、问数高亮、证据、详情和评审，不在本次集成范围内。

搜索支持类别、实例、关系和数据属性；关系/属性详情显示定义、作用对象与目标类型。搜索恢复完整类别范围。
超过同屏 300 节点或 600 连线的修订会提示范围过大并保留上一版；修订标记只有在更新成功后变化。首次读取超限时明确提示，不显示虚假的成功结果。
图谱与设计请求的总时限为 30 秒，包含响应体读取；离开页面取消未完成请求。超时显示重试提示；设计读取失败后停止自动轮询，可重新打开页面读取当前状态，不自动重发写操作。服务端拒绝超过 20,000 实体或 100,000 连线的投影，关系组合在分配前检查。

## 接口及页面升级

设计会话和历史修订的只读展示字段为 `interactive_graph_view`，schema 为 `datamind-interactive-ontology-graph/1`。固定版本接口为 `/api/ontology-assets/<ontology_id>/versions/<version_id>/views/interactive-ontology-graph`，页面深链使用 `view=interactive-ontology-graph`。

升级服务后刷新页面，从本体库重新打开图谱以获取当前链接；外部调用方同步更新路径、字段和 schema。已保存本体、设计会话和资产版本不需要重写，旧实例关系入口 `view=relations` 仍可使用。
