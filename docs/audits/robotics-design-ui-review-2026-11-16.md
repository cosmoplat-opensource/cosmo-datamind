# 机器人本体构建设计展示优化（DR-070）

本文件先记录初版优化；用户随后要求隐藏核对区域，最终调整见文末。

用户反馈类别、关系、属性展示过多，且“待明确项”难以理解，要求优化现有页面。
本次完成摘要优先、详细表格／模型说明／技术标识折叠、阶段指引和业务语言解释；核对信息显示总数及前三项，其余可展开。

仅改前端展示和本地草稿交互；未修改构建 API、模型提示、本体事实、确认流程或用户原始数据，未创建提交。

用户希望先构建本体、后续通过应用检查和本体修订处理具体缺项，要求简化核对信息展示。

后台 clarifications、模型上下文、确认快照和导出事实不变；未回答备注本身不是生成阻断条件，实际缺少的结构或任务信息仍由原应用检查阻断。
桌面 1440px／窄屏 390px 演练确认五项后台备注保留、页面不渲染核对列表、确认按钮可用、手动编辑可用、历史不渲染核对列表、无写请求／页面错误／横向溢出。
当前验证证据位于 `.check-results/robotics-design-hide-notes/`；初版截图与报告仅代表调整前状态。
