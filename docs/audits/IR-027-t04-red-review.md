## 历史读取锁冲突

HTTP 并发用例稳定复现了 `database is locked`：历史读取线程到达真实不可变 OWL 文件读取时，用事件暂停它；另一连接修改无关的数据本体名称，提交受到读事务阻塞。
测试只延迟自己副本中的指定文件读取，随后释放并确认历史接口正常返回，失败明确落在并发提交。
这为 T05 修复读取事务边界提供依据，不能通过取消文件或来源校验解决。
另外两项篡改测试继续要求历史查看和 XML 下载返回完整性错误。
这里没有冻结通用 20 秒响应 SLA；真实大资产时延和用户本体副本的性能对照留在 T06。
