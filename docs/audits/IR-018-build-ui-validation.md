| 重试和历史 | failed/interrupted 才能重试；新 run 保留原来源和 retry_of；重试也检查容量/幂等，旧结果不改；读取与重启不重跑终态任务 | 可以追溯“第一次失败、第二次重试”，刷新不会重复构建 |
