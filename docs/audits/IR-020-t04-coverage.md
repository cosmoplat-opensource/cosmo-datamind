## 真实链路与替代边界

浏览器使用真实 Chromium、隔离 Gunicorn、SQLite、双 XML 构建、OWL 保存及编译和下载接口。
外部模型替换为本机 HTTP 测试服务；不通过 page.route/fulfill 替代补齐、构建、存储或生成接口。
完整补齐场景从原始双 XML 构建开始，按页面提交映射、确认和适配资料；参数场景还移除曝光时间，经页面补 155 后继续生成并核对 XML。
独立 XML 预期从冻结 XML 的六个公开位置赋值构造，不调用 compiler.instantiate 计算预期答案。
完整资料夹具仅用于验证已有完整本体直接生成、错误和持久化；不替代从缺知识开始的补齐测试。
夹具中的时间、确认、资料和参数均为软件测试合成输入，不是现场标定结论。

测试编写中发现两处夹具边界并在审查前修正：缺字段的候选只能按候选存储契约保存，不能先经过严格发布器；发布器规范化端口声明后，合成适配资料必须针对规范化后的图登记，不能沿用旧摘要。
未修改既有 77 项测试、历史冻结测试、生产 SHACL 或证据校验规则。

## 旧 UI 契约如何处理

| 既有内容 | T05 处理 | 本批测试约束 |
|---|---|---|
| 双 XML 上传、构建模板、构建状态、OWL 下载 | 保留，增加直接进入任务的主操作 | 原构建测试不变；新浏览器覆盖主操作 |
| 本体目录与原数据图谱/评审/对话入口 | 保留 | 新旧真实浏览器均核对 |
| 机器人知识/评审显式深链接 | 作为兼容路径保留；不作为默认生成前置步骤 | 原 IR-019 浏览器全部保留；新增兼容对照 |
| 默认生成页的固定版本/底本/工作头、多页签和通用署名表单 | 用一个当前版本和按需补齐代替 | 新任务页明确断言这些输入和页签不存在 |
| 模型设置 | 增加可选 bt_extract，不改变已有任务选模 | 页面保存后核对实际模型请求 |

本批没有删除或修改旧测试断言。
旧浏览器先从版本详情点击“维护知识”，再通过显式 `tab=knowledge` 进入高级维护；该次级入口需保持可直接访问。旧测试没有要求新基础任务页展示高级表单，因此无需删改旧测试。
