## 实现

构建入口复用平台模型配置，完整配置时开放模型路径；无配置时继续旧 XML 构建，错误配置阻止提交。
模型与离线路径共用构建页面，显示实际方式，离线明确说明建模要求不参与语义建模。
模型准入进入持久化设计会话；类别、关系属性、骨架确认和确定性实例抽取均有显式操作。
设计 HTTP 严格校验请求字段、修订号、阶段与快照；复用服务幂等与平台 Host／Origin／JSON 防护。
只读会话、修订与导出不迁移、不恢复、不调用模型；设计运行复用运行详情、事件和工件下载。

新增单宿主设计执行器，以独立文件锁协调宿主，只在取得执行权后恢复遗失运行为 interrupted。
正常队列自动执行，等待用户确认不占运行；重启不自动重放失联的模型请求。
模型等待在设计执行线程中发生，不持有数据库写锁或 RDF 锁；服务提交继续复验固定输入和运行身份。
旧构建执行器和新设计执行器按不同 operation 领取，旧运行恢复不受影响。

前端增加设计控制器，处理重复点击、传输重试编号、输入保留、迟到响应、轮询和历史读取。
同页工作区支持建模要求、类别／骨架确认、返回类别修改、失败重试、历史对比和候选导航。
模型回复与设计字段经文本转义，不执行模型生成的 HTML。
候选详情、总 JSON／OWL 下载、通用图谱和目录均识别设计契约。
应用资格按实际固定版本检查；不兼容候选从任务选择项过滤，详情和图谱显示原因，任务后端仍执行消费检查。
完整 JSON 下载直接返回保存字节，未改为下载时拼接，也未拆分业务 JSON。
