# 多数据库功能与界面复核

实施日期：2026-10-12；最终复核跨至 2026-10-13。对应 DR-095。

## 1. 数据及范围

本轮在已有未提交修改上继续实施，保留 DR-093 研究能力和 DR-094 清理结果。
重点是已登记 SQLite 数据库的前后端来源一致性，不将连接到其他数据库类型的已有能力改写为 SQLite。

| 来源 | 物理文件 | 实际表数 | 用途 |
|---|---|---:|---|
| 示例主库 `demo` | `examples/demo_metrics.db` | 108 | 默认来源及切回验证 |
| `conn_99f38b` | `data/contract200v3/contract_200.db` | 200 | 多库切换及大规模图谱验证 |

两库均含 `fact_sales_order`，行数同为 4,731，不能用该表的计数证明来源切换。
实际验收使用 200 表库独有的 `dim_asset_class`，并检查切回 108 表库后返回 404。
200 表库本体含 207 个节点、146 个指标条目及 610 条关系；节点含角色和事件等表示，不能把节点数等同物理表数，条目数也不代表全部已验证。

## 2. 功能变化

侧栏增加当前数据库选择器，统一总览、目录、质量、术语、图谱、指标、问数、本体编辑、构建、来源相关动作记录及评测的数据上下文。
每个请求按登记 ID 解析来源，不修改进程全局数据库路径；同一文件的重复登记按实际文件识别。
工作线程继承请求上下文。无效来源、来源已失效的本体和跨库混选明确拒绝，不回退默认库执行。

SQL 工作台及可视化允许单独选择来源；保存看板逐图保留来源并显示名称。
200 张物理表全部进入可视化快捷选项，去掉前 120 张的限制。
全局切换重新加载页面并保留各库草稿；局部可视化切换丢弃旧请求晚到结果。
数据统计缓存、问数结果、SQL 技能、会话、反馈和动作记录按来源区分，补上旧 ID 跨来源编辑的拒绝处理。

大型图谱默认采用力导向全图，保留分层、环形、辐射、缩放、平移、节点和关系详情；用户手选布局不会被自动覆盖。
全图用于查看结构，放大或点“可读”查看文字。大量关系的全图仍可能存在连线交叉，不将其描述为所有标签在同一屏幕均清晰可读。
单值指标卡不再无依据地标为“末期”；多行指标只标明选用的最后一行。

未构建本体的数据库仍可预览、运行只读 SQL 和制作图表；问数和本体编辑提示先构建。
非默认库内置的简单行数评测标识为功能检查，不作为业务问数准确率或论文结果。
连接、模型配置、通用技能和任务管理仍属于整个工作区，来源筛选不是租户权限控制。
