概念长什么样什么时候用机器人领域用它做什么
页面侧栏一项，点一下整屏切换 一个独立的功能，需要自己的导航位置不新增 —— 一个领域不配拥有新页面
面板嵌在既有页面里的一块，跟着当前选中的对象出现 内容依赖上下文，脱离上下文就没意义设备详情、参数摘要、该对象可用哪些技能
抽屉从右边滑出，盖在当前页之上，关掉就没了 要展开做一件正经事，但不值得占一个页面行为树编排（要编译、要校验、要 diff）
Tab同一页面内并列的视图 几个并列的子视图，共用同一套上下文契约中心里的「指标契约 / 参数契约」；本体构建里的「构建本体 / 编排行为树」
一句话：领域不是页面，领域是挂到既有页面上的面板； 面板不够用的时候，才升级成一个抽屉；永远不需要新页面。
分工：做产物在「本体构建 → 编排行为树」（输入自然语言 + 本体）； 看产物在「产物库」点开，弹出的就是下面这个抽屉。技能节点上没有「编译」按钮 —— 技能只是被调用者，一棵树的主语是「一次任务编排」。
动手试：① 点左边图谱里的节点 → 右侧详情面板会换，里面的蓝色虚线框是「面板」； ② 点详情面板里的「以此技能为起点编排」→ 抽屉从右边滑出来； ③ 抽屉里点顶部的 Tab → 切「编译报告 / 与现有树对比」；④ 点抽屉右上角「关闭」或按 Esc → 抽屉收回，原页面原样还在。
