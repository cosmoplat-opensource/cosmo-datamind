# 行为树生成应用

对应 DR-069 / IR-023。

## 从哪里开始

左侧导航打开 **本体应用 → 行为树生成**。
它与深度问数并列，首页可以选择机器人本体，再点“开始新任务”。
机器人本体关系图顶部也提供“基于此本体生成行为树”，直接使用正在查看的本体版本。
本体库卡片仍只保留“打开图谱”。

进入任务后，输入任务描述，点击“生成行为树”。
系统沿用现有澄清和按需补齐流程，只提示当前任务缺少的信息。
生成成功后可以预览并下载行为树 XML。

## 一个本体可以有多份行为树

本体提供知识和配置，任务描述决定这一次要生成什么。
同一本体可以创建多个独立任务；创建新任务不会覆盖旧任务的结果。
一个任务经过配置调整后再次成功生成，前后两份结果也分别保留。

## 历史记录怎么看

页面左侧展示“任务与生成记录”，包含已生成结果及尚未完成的任务。
每条显示任务描述、本体名称、可读版本号、状态和时间。
支持按任务描述或本体名称搜索，点击“加载更多”查看更早的记录。
侧栏可以折叠；窄屏下在任务工作区上方显示。

- 点击已生成记录：查看当时保存的结果，预览和下载都对应这一次生成的 XML。
- 点击未完成任务：恢复该任务，继续澄清或补齐信息。
- 点击“新建任务”：返回本体选择首页。
- 历史结果中的“基于此本体新建任务”：基于该结果使用的固定版本另开任务。
- 历史结果中的“查看对应本体”：查看生成时使用的本体版本。

首页选择本体时使用它当前登记的版本；从图谱或历史结果进入时使用该页面对应的固定版本。
因此同名本体的历史结果可能显示不同版本，这是生成依据的差异。

## 保存与兼容

记录保存在现有本地任务和运行存储中，刷新页面或重启服务后仍然存在。
查看首页和历史结果不调用模型，也不创建新任务。
旧记录能够继续发现；缺少时间的旧任务显示“旧记录”，已有生成运行使用其原始生成时间。
旧任务描述优先从已保存的对话响应恢复，不改写原有本体和记录。

结果读取和下载会检查固定本体、运行清单及 XML 文件的一致性。
如果文件损坏，页面会提示失败，不会展示另一份结果来替代。
生成物仍是离线候选行为树，不代表已通过机器人设备执行验证。
构建时上传的来源行为树仍不在本体浏览界面展示。
