# 浏览机器人本体图谱

## 打开本体关系图

1. 打开本体库，在“本体领域”选择“机器人本体”。
2. 在目标卡片点击“打开图谱”。
3. 默认展示业务对象与配置；可切换“技能与流程”或“全部对象”。
4. 点击节点或从右侧“节点详情”列表选择，查看属性和关联关系。
5. 输入名称并点击“查找”定位节点；多项匹配时再次点击查找可逐项定位。
6. 拖动画布或节点调整阅读位置，滚轮及加减按钮缩放，“适应画布”恢复整体视野。

颜色：蓝色是业务对象与配置，紫色是技能与流程，青色是其他命名实例。
本图展示当前版本的命名实例，不展开 OWL 类定义、匿名限制和审计记录；不是完整 RDF 序列化内容的逐三元组画布。

## 打开行为树视图

1. 从本体库点击“打开图谱”，再点击左上方“返回本体详情”。
2. 在详情页点击“打开行为树视图”。
3. 默认显示 main 主流程；使用“行为树”下拉框切换感知、抓取或放置子树。
4. 节点按从上到下的层级展示，Sequence 的同级步骤按从左到右的顺序排列。
5. 点击节点查看原始节点类型和参数；选中 SubTree 节点后，可点击侧栏按钮打开对应子树。
6. 点击工具栏“返回上一级”回到刚才的树和引用节点；直接从下拉框选择子树时，点击“返回主流程”。

机器人本体卡片只保留“打开图谱”。“生成行为树”、固定版本信息和下载入口位于本体详情页。

此处是**本体流程，不是任务生成结果**：它直接展示选定本体版本保存的流程与绑定，不调用模型、不要求先生成任务，也不保证已经完成具体任务的参数补齐或实机适配。
某次任务的最终参数和 XML 仍在该任务的生成结果中查看。

## 版本与只读行为

两种视图都固定到入口所选版本，显示本体名称和“版本 N”，刷新不会自动换成最新版本。
拖动、搜索、切换子树不会写入本体，也不会创建新版本或任务。
无效版本、文件损坏或过大投影将提示错误，不自动回退到旧数据。
