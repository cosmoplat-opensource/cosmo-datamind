# 浏览机器人本体图谱

## 打开本体关系图

1. 打开本体库，在“本体领域”选择“机器人本体”。
2. 在目标卡片点击“打开图谱”。
3. 默认展示业务对象与配置；可切换“技能与流程”或“全部对象”。
4. 点击节点或从右侧“节点详情”列表选择，查看属性和关联关系。
5. 输入名称并点击“查找”定位节点；多项匹配时再次点击查找可逐项定位。
6. 拖动画布或节点调整阅读位置，滚轮及加减按钮缩放，“适应画布”恢复整体视野。

颜色：蓝色是业务对象与配置，紫色是技能与流程，青色是其他命名实例。
本图展示当前版本的命名实例，不展开 OWL 类定义、匿名限制和审计记录；不是完整 RDF 序列化内容的逐三元组画布。

## 查看任务生成的行为树

构建来源中的行为树暂不向用户展示，本体详情和关系图均不提供该入口。
旧来源树链接会提示进入本体详情创建任务，不会加载或显示来源树。

1. 从本体关系图点击左上方“返回本体详情”。
2. 点击“生成行为树”，输入任务描述，按提示补齐所需信息。
3. 生成完成后，在该任务结果中预览行为树或下载 XML。

## 版本与只读行为

本体关系图固定到入口所选版本，显示本体名称和“版本 N”，刷新不会自动换成最新版本。
拖动、搜索不会写入本体，也不会创建新版本或任务。
无效版本、文件损坏或过大投影将提示错误，不自动回退到旧数据。

历史感知与放置配置在图谱和任务页统一显示为“源文件感知配置”“源文件放置配置”；是否绑定以实际关系为准，显示名称不代表绑定状态。
